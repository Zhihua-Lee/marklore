# Folio Notes

**面向 Windows 的离线 Markdown 笔记应用。**

在同一个工作区阅读、编辑和整理本地笔记：用多标签与分组组织材料，用目录和链接预览穿梭长文，用数学公式、代码和图表记录技术内容。笔记始终是普通文件，无需导入专有数据库。

[快速开始](#快速开始) · [使用指南](docs/user-guide.md) · [开发指南](docs/development.md) · [验证记录](VERIFICATION.md)

## 功能

| 能力           | 说明                                                                 |
| -------------- | -------------------------------------------------------------------- |
| 阅读与编辑     | 阅读、双栏编辑、源码三种模式；格式工具栏、块级就地编辑与源码定位。   |
| 数学与技术写作 | KaTeX 公式、Mermaid 图表、代码语法高亮、表格、任务列表和脚注。       |
| 多文档工作区   | 可拖动标签、彩色分组、文件夹浏览和包含子目录的文件名筛选。           |
| 长文导航       | 标题目录、嵌套章节折叠、本地链接悬浮预览与前进／后退历史。           |
| 阅读外观       | 深浅主题、内置字体、字号与字重设置、可调整侧栏和表格样式。           |
| 本地保存与导出 | 显式保存、磁盘版本检查、备份与草稿恢复；导出 PDF 或离线单文件 HTML。 |

## 快速开始

### 从源码运行

开发基线为 **Windows、Node.js 24、pnpm 11**。首次安装依赖需要联网，构建后的桌面应用可离线使用。以下操作面向仓库所有者及已获授权的使用者。

```powershell
git clone https://github.com/Zhihua-Lee/folio-notes.git
cd folio-notes
pnpm install --frozen-lockfile
pnpm build
pnpm start
```

`pnpm start` 启动 Electron 桌面应用；`pnpm dev` 仅启动浏览器 UI 演示，不提供原生文件访问。构建与测试的完整说明见[开发指南](docs/development.md)。

### 使用已有 Windows 构建

解压完整应用目录，运行 `Folio Notes.exe`。保留同目录的 DLL、`resources` 和 `locales`，不要只复制 EXE。当前构建未代码签名，Windows 可能显示未知发布者提示。

进入应用后，用 **打开文件** 选择 Markdown，或用 **打开文件夹** 添加笔记库；也可以直接把 Markdown 文件拖入窗口。`Ctrl+N` 新建笔记，`Ctrl+S` 保存。

## 使用方式

| 模式 | 用途                                                          | 快捷键   |
| ---- | ------------------------------------------------------------- | -------- |
| 阅读 | 专注于渲染后的正文、目录、折叠和链接预览。                    | `Ctrl+1` |
| 编辑 | 左侧编辑 Markdown，右侧实时预览；也可在预览中编辑单个正文块。 | `Ctrl+2` |
| 源码 | 使用完整 Markdown 编辑器处理内容与结构。                      | `Ctrl+3` |

三种模式共享同一份草稿。切换模式或标签保留阅读位置；`Aa` 集中管理字体、主题、侧栏、表格和后台设置。更多操作见[使用指南](docs/user-guide.md)。

## 数据与兼容性

**只有显式保存才写回 Markdown 原件。** 恢复草稿与工作区状态保存在本机；保存前检查磁盘版本，发现外部修改时提供冲突处理。图片附件放在笔记旁的 `assets` 目录，移动笔记时应一并保留。

应用不提供云同步、遥测或自动上传，远程图片不会自动下载。本机恢复数据包含明文草稿和文件路径，备份不自动过期；数据目录、容量限制及恢复方式见[保存与恢复](docs/user-guide.md#保存与恢复)。

项目目前为 **Windows 桌面预览版**。复杂公式按 KaTeX 支持范围渲染；首次打开超长文档或大量公式／图表仍可能有明显开销。具体版本以 [package.json](package.json) 为准，已执行的测试及其范围见[验证记录](VERIFICATION.md)。
