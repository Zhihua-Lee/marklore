# Folio Notes

独立实现的离线 Markdown 笔记桌面应用，Windows 预览版 v0.1.19。

这是完整应用源码，不是 MDLook 补丁，也不需要安装 MDLook。构建、使用与修改须遵守下方许可证说明。项目不包含 MDLook 的实现、资源或二进制；现有 MDLook 安装与笔记不会被迁移、覆盖或改变默认关联。

## 运行

发行包解压后，双击 `Folio Notes.exe`。请保留同目录的 DLL、`resources`、`locales` 等文件，不能只复制 EXE。

- “打开文件”可选择多篇笔记；“打开文件夹”将目录加入左侧笔记库，搜索包含未展开的子目录。
- 起始页只提供打开与新建入口，不自动创建演示笔记；最后一个标签关闭后返回起始页。
- 阅读 / 编辑 / 源码共享文档，切换模式或标签时保留阅读位置与编辑历史。
- 编辑 / 源码区内提供格式工具栏：标题 1–6、正文、粗体、斜体、删除线、引用、有序 / 无序 / 任务列表、行内代码、代码块、公式、链接、图片、表格和分割线。作用于当前选区或所在行；每次格式操作可整体撤销 / 重做，不经过 HTML 转换。Ctrl+B / I / E / K 分别为粗体、斜体、行内代码、链接。
- 插入代码块时可选语言；表格可选 1–12 列、1–30 行，首行为表头，Tab / Shift+Tab 可在已有单元格间移动（跳过分隔行）。保留源码 / 预览双栏编辑。
- 行内公式、块公式与分割线均直接显示在格式工具栏中，不藏在“更多”菜单。
- 高亮 / 文字颜色按钮左键直接使用上次颜色；图标下的色条显示当前记忆颜色。右键或聚焦后按 ↓ 展开紧邻按钮的调色板，空间不足时向上展开；可选预设、自定义或清除，Esc 收起。颜色记忆在源码和就地编辑之间共享，并在重启后保留。
- `Aa → 表格` 可选柔和卡片、简洁横线或经典网格，以及自适应内容 / 铺满正文两种宽度；默认柔和卡片、自适应宽度。长文字换行，无法缩窄的内容局部横向滚动。HTML / PDF 导出保留所选风格及宽度。
- 阅读区和链接预览按实际文字排版优化普通表格列宽，优先减少自动换行，而非平均分列或由单个超长单元格占走大部分空间。中文、粗斜体和行内公式参与实测，字号不变；若候选布局让整表更高，则保留原布局。空间足够时仍紧凑显示，空间不足以容纳完整词语 / 公式时允许局部横向滚动。宽度和字体变化后重新计算，结果缓存，多表格分批处理。合并单元格、嵌套 / 图文复杂表格及作者指定列宽保持浏览器原生布局；这不是任意表格的全局最优排版保证。
- 鼠标悬浮时，表格边缘轻微增强、当前行淡色高亮；图表和图片增加细边缘与轻阴影。没有放大、位移或正文透明度变化，过渡遵循系统减少动态效果设置。
- 仅在编辑模式中，悬浮预览正文块后点击铅笔即可就地修改；聚焦预览区后也可按 Alt+Enter。阅读模式不显示铅笔或编辑高亮，也不响应此编辑快捷键。仅当前块变为 Markdown 编辑区，其余内容保持渲染。支持标题、段落、列表、引用、表格、代码、公式和分割线；复杂块保留完整源码，不将整篇 HTML 反向转换。原始 HTML 块请在源码区修改。Ctrl+Enter 完成，Esc 取消此块的本次编辑，双击定位功能不变。
- 就地编辑提供粗体、斜体、行内代码、链接、图片与撤销 / 重做。输入立即进入共享草稿与恢复记录，但仍需显式保存才写回磁盘；切换标签或模式会保留输入。它是块级 Markdown 编辑，不是任意富文本所见即所得编辑器。
- 源码与就地编辑均提供文字高亮及颜色：六种预设、自定义颜色、清除，支持撤销。预设色适配深浅主题；自定义色保留指定值。工具按编辑历史、文字样式、段落结构、插入内容分组。颜色以标准内联 HTML `<mark style="…">` / `<span style="color: …">` 写入 Markdown，保留粗斜体及标题结构；不要求其他查看器安装专用插件，但对方须允许内联 HTML。HTML / PDF 导出保留这些样式。
- 图片支持文件选择、剪贴板图片粘贴，以及从资源管理器拖入；就地编辑区也支持。图片复制到笔记旁 `assets` 文件夹，以相对路径引用，不移动或覆盖原图。未命名笔记须先保存。一次最多 20 张、每张最多 32 MB、合计最多 64 MB；剪贴板像素转换为 PNG，文件形式的 GIF 保留动图。撤销只撤销 Markdown 引用，不自动删除附件；移动笔记时请带上附件目录。远程图片仍不自动联网下载。
- 既有本地图片加载失败时显示原因和重试入口。跨出笔记/笔记库目录的图片可点击“授权加载图片…”：选择仅本次加载该图片，或记住该图片所在目录（含子目录）。目录授权只允许图片读取，不扩大 Markdown / 附件访问权限；保存在本机恢复设置中。路径不存在或文件损坏不会被当作授权问题。
- 标签栏随数量自动收缩，达到最小宽度后可用滚轮或两侧箭头浏览。拖动标签可调整顺序，边缘自动滚动，顺序在重启后保留；Esc 取消拖动。右键可刷新、在资源管理器中显示原文件、关闭；聚焦标签后用方向键切换，Ctrl+Shift+左右键移动当前标签。
- 标签右键可新建分组、移入已有分组或移出分组。组名显示颜色、篇数及未保存提示；点击折叠 / 展开，右键修改名称和颜色或取消分组。折叠不关闭笔记，取消分组也不删除文件。拖入组名将标签追加到组内，拖到组内标签可调整位置，拖到未分组区域可移出；拖动组名可整体移动。聚焦组名后 Ctrl+Shift+左右键也可移动整组。名称、颜色、顺序与折叠状态随会话保存。
- 鼠标前进 / 后退侧键或 Alt+← / → 沿阅读历史往返：记录标签切换、文件链接、目录及锚点跳转，不把普通滚动或悬浮预览当作新一步。不关闭、不替换或重复打开标签；已主动关闭的标签从历史移除。导航保持各篇笔记当前模式和未保存草稿，恢复源码锚点附近的阅读位置，并按需展开目标章节 / 标签组。后退后新跳转会替换原前进分支。
- `Aa → 阅读导航` 可选择全部笔记 / 仅当前笔记，以及是否显示前进 / 后退按钮。按钮默认隐藏，快捷键始终有效；它们与浏览标签栏的左右箭头不同。阅读历史只在本次运行中保留，最多 200 个位置；重启仍恢复每篇笔记的最后阅读位置与分组。应用内编辑会同步调整历史源码位置；外部大幅改写后的定位可能只能接近原位置。
- 可将多个 Markdown 文件从资源管理器拖入窗口打开；已打开文件只切换到原标签，不覆盖未保存草稿。不支持的文件会提示，不导入其内容。
- 文件夹默认在左、本文目录在右；各自开关固定在应用窗口对应侧的上角，不随侧栏开合移动。`Aa` 中可分别选左侧、右侧或隐藏，选择会记住。
- 文件夹浏览默认展开当前笔记所在目录并高亮该文件，保留另行添加的笔记库；同目录反复开关不重复扫描，刷新按钮可重新读取。文件夹选择对话框也从当前笔记位置开始。
- `Aa` 可独立设置文件夹/目录字号（10–14px，默认 12px）及标签字号（10–13px，默认 11px），导航文字采用常规字重。
- 阅读/编辑/源码采用分段控件，选中底块短暂滑动，正文不进行缩放或透明度动画。标题采用 1.85 / 1.5 / 1.25 / 1.1 / 1 / 0.95 倍的六级尺度，保留粗体和斜体含义；分割线与所在内容块等宽，折叠箭头和章节竖线共用对齐轴。
- 目录标题支持公式、粗斜体与行内代码；点击仍定位到正文标题，链接和图片不会在目录中触发外部加载。
- 文件操作按打开、保存、导出排列；新建紧跟标签列表，阅读 / 编辑 / 源码、宽度、主题与最右侧 Aa 相邻。窄窗口仍保留这些入口。
- 窄版最大外框 760px，常规阅读时左留白 32px、右留白 48px，正文行宽 680px；窗口不足时随可用空间收缩。
- 窗口最小尺寸为 480 × 360 个逻辑像素，适配常见半屏贴靠；760px 及以下两侧栏作为浮层显示，不挤占正文，可用各自按钮收起。
- 章节按标题层级递归缩进。折叠箭头对齐标题首行，竖线从箭头下方留白后延伸，不穿过图标；悬浮时箭头和细线一起高亮，折叠后显示块数与短虚线尾部。点击竖线或箭头可折叠，支持键盘操作，并记住折叠状态。
- 标题折叠后的悬浮反馈覆盖标题行、摘要、三角和竖线；摘要也可点击展开。`<details>` 折叠卡片的边框、摘要行和三角同步响应悬浮及键盘焦点，保留笔记自定义文字颜色；不缩放、不移动内容，遵循减少动态效果设置。
- 阅读区使用中性暖灰底色、克制的分割线和细滚动条，统一列表、引用与公式间距。底部不再重复显示文件路径和进度；未保存状态保留在标签圆点，悬浮标签可看完整路径。
- 正文字号 50%–200%；`Aa` 集中设置字号、字体、浓度、主题和侧栏位置。默认内置 Literata 可变字体（16px、行高 1.7），代码使用内置 JetBrains Mono，界面使用 Inter；中文优先使用本机思源黑体（Noto Sans SC），缺少时回退微软雅黑。仍可选择思源黑体、Arial / 微软雅黑、Cambria / 宋体。不内嵌 Windows 商业字体。
- 旧版默认黑体预设在升级时切换为 Literata；此前选择的 Arial / Cambria 会保留。所有字体预设仍可在 `Aa` 中自行选择。
- `Aa → 恢复书页排版` 切换为 Literata 与自然浓度，保留字号和布局。自然浓度保持常规 400 字重，不随缩放突然加粗；段落、列表、引用与表格共用正文浓度，Markdown 粗体单独强调。仍可手动选择更浓的正文。
- 公式保留 KaTeX 字体及数学粗斜体含义，中文公式文本使用正文中文字体。不使用文字描边、CSS 缩放或降低设备像素比。
- 保存右侧的导出按钮提供 PDF / HTML 导出；Windows 原生菜单栏隐藏，保留快捷键。侧栏开合与目录导航有短过渡，正文不做缩放或透明度动画，遵循系统减少动态效果设置。
- 支持 Markdown 表格、任务列表、脚注、代码高亮、`<details>`、本地图片 / GIF、KaTeX 数学公式和 Mermaid 图。
- 代码块提供语言标识和复制按钮，复制原始代码文本（包括缩进和换行），显示成功或失败反馈。浅深页面都使用经典炭黑代码底色，搭配紫色关键词、橙色字符串、绿色注释和常规字重 JetBrains Mono；未知语言按纯文本显示。Mermaid 图使用页面主题，仍可复制源代码；导出保留深色代码主题，不包含复制控件。
- 应用、托盘、窗口和起始页统一使用原创双页折角标记；Windows 图标含 16–256px 多个分辨率。
- 外部程序修改文件后，已保存文档自动刷新；有未保存修改时显示冲突选择，不静默覆盖。

### 托盘、后台与系统集成

Windows 托盘图标可重新打开窗口、隐藏窗口或完全退出；`Aa → 后台与系统` 提供同样的管理入口。

- “关闭窗口后留在托盘”默认关闭。开启后，窗口关闭按钮只隐藏窗口，标签、位置和未保存草稿保留；托盘“退出 Folio Notes”仍会完全退出，并对未保存笔记提示。
- “开机启动到托盘”默认关闭，只在主动开启时登记当前程序。登录后不弹出阅读窗口；从资源管理器打开 Markdown 会唤回窗口并打开该文件。Windows 启动管理可独立禁用启动项。
- 隐藏前等待恢复草稿写入，但不自动覆盖 Markdown 原件。后台仍占用内存；文件变化使用系统通知而非定时轮询，隐藏时合并更新，恢复窗口后再检查。
- “注册／更新 Markdown 支持”仅将本程序加入当前用户的 `.md` / `.markdown` 候选应用。然后点击“选择默认应用…”在 Windows 中选择 Folio Notes；Windows 10 在默认应用页选择“按文件类型指定默认应用”。不会直接修改受保护的默认选择，也不需要管理员权限。
- 便携版移动、升级到新目录后，应从新版本重新注册文件支持并更新启动路径，再移除旧目录。设置中会提示检测到的旧路径；不自动更改其他版本的系统设置。

### 链接悬浮预览

将鼠标停留在本地 Markdown 链接约 350 毫秒，即可在浮层阅读目标内容，不新建标签、不改变当前阅读位置。移入浮层可滚动、选择文字、展开折叠块；“打开”才正式导航。

预览底部的 A− / 百分比 / A+ 可独立调整 50%–200% 字号，点击百分比恢复 100%。该设置会保留，不改变主阅读区字号；预览中的代码块同样支持复制。

```markdown
[另一个笔记](other.md)
[某个标题](other.md#中文标题)
[行列位置](other.md#L40C5)
[带空格的文件](<Folder/Other note.md#heading>)
```

标题使用小写 slug，空格变为 `-`，保留中文；重复标题依次追加 `-1`、`-2`。也支持显式 HTML `id`。无法找到锚点时会明确提示并显示文档开头，不伪装成精确定位。

若目标标签有未保存修改，预览优先显示该草稿；否则重新读取磁盘内容。预览仅访问当前文件夹、已添加的笔记文件夹或已打开的文件。越界链接不会仅因悬浮就请求授权：请点击链接确认，或先添加文件夹。网页链接不后台抓取或预览，点击后确认在系统浏览器打开。

本地 Markdown / 文本链接在应用内打开。PDF、Office 文档、图片、常见音视频及压缩包等受支持附件，点击后直接交给系统默认软件打开，不再二次确认；没有关联软件时会提示。可执行程序、脚本和快捷方式不直接启动，未知类型请通过文件夹打开。附件不会被误当作 Markdown 标签读取。外部网页及越界 Markdown 的授权确认仍保留，悬浮不会自动打开附件。

键盘也可使用：Tab 聚焦链接后显示预览，F2 进入浮层，Esc 关闭并返回链接。

### 定位与公式

正文双击普通文字可在编辑器中选择对应源码；编辑器双击可定位预览。定位依赖源区间，公式、图表、复杂 HTML 使用源码块定位，**不是公式字形与 LaTeX 命令逐字一一对应**。

数学支持 `$...$`、`$$...$$`、`\(...\)`、`\[...\]` 以及部分常用对齐环境；表格中的数学竖线不会作为列分隔符。支持 `\xrightarrow{...}` 等带文字的箭头。针对复制时过度转义的独立 `\\[` / `\\]` 公式块，有限兼容被转义的下标、上标星号及间距，不改写原文，不处理代码块，也不合并正常矩阵换行。建议新写公式仍采用标准 TeX。

KaTeX 不等于完整 TeX 引擎；未知命令显示可检查的错误与原式，不输出内部占位符。完整 LaTeX 包、自动跨公式编号、任意自定义宏及所有 Markdown 方言不在本版保证范围内。

块类型支持范围：标题及嵌套章节折叠、段落/粗斜体/行内代码、列表/只读任务勾选、引用、表格、分割线、脚注、details 折叠、代码、公式、Mermaid、本地图片/GIF。任务项内容在编辑模式修改；阅读和悬浮预览不直接改写文件。远程图片和任意 HTML 脚本仍禁止加载，不为展示效果放宽安全边界。

### 导出

保存右侧的导出菜单提供 **导出 PDF** 和 **导出 HTML**，使用当前标签的最新内容，包括尚未保存的编辑。折叠章节与 details 在导出时展开；导出不保存或更改 Markdown 原件。

HTML 是可离线打开的单文件，包含正文样式、公式字体、Literata / JetBrains Mono 字体及已授权的本地图片；Mermaid 转为静态图。PDF 使用同样的浅色排版，动图在 PDF 中为静态画面。中文仍依赖本机字体，远程图片不联网下载；无法嵌入的内容会提示。导出文件可能包含笔记中的本地链接，分享前请检查正文与链接中的私人信息。

## 数据安全与隐私

应用本身没有云同步、遥测或自动上传。笔记仍是原来的普通文件；OneDrive 等外部同步工具的行为不受本应用控制。

- 仅显式保存才写回笔记。保存前校验磁盘版本，并使用同目录临时文件替换，保留覆盖前的备份。外部写入恰好发生于最终校验与替换之间仍存在极短竞态；这不是跨进程文件锁或云同步事务。
- 草稿与标签状态自动写入本机 `session.json`；持续输入最迟约 5 秒触发一次，正常退出等待保存恢复状态。异常断电仍可能丢失最近数秒输入。
- 默认数据目录由 Electron 的 Windows `userData` 决定（通常 `%APPDATA%/folio-notes`）。其中包含明文草稿、文件路径和 `backups`；不要公开上传该目录。备份当前不会自动过期，需要自行管理空间。
- 可以在启动前将 `FOLIO_DATA_DIR` 环境变量设为一个绝对路径，隔离配置与恢复数据。不要将多个正在运行的实例指向同一数据目录。
- 最多 100 个标签、单文件 32 MB；会话有 64 MB 总大小限制。超限会明确报错，不静默截断草稿。请及时保存大型草稿。
- 渲染进程无 Node / 文件系统权限；本地访问经隔离接口授权。HTML 清理、严格图表策略、禁止权限请求与远程图片加载。UNC / 网络共享链接暂不支持。
- 系统集成仅在用户主动开启或注册时写入当前用户设置，不自动抢占默认应用，也不替换原查看器。

## 开发与构建

本项目已在 Windows、Node.js 24 与 pnpm 11 上验证。首次安装 / Electron 下载需要网络，构建后的应用离线运行。

```powershell
pnpm install --frozen-lockfile
pnpm build
pnpm start
```

`pnpm dev` 是浏览器 UI 演示 / 测试服务，不具有原生文件访问能力。桌面代码修改后需重新构建前端，再启动 Electron。

```powershell
pnpm test
pnpm test:ui
pnpm test:native
pnpm test:native-safety
pnpm test:native-menu
pnpm test:native-export
pnpm licenses
pnpm dist
```

浏览器测试使用安装在 Windows 上的 Microsoft Edge；原生测试启动独立 Electron，并只读写新建的临时测试目录，不使用个人笔记。打包输出 `release/win-unpacked/`，不签名、不自动发布。可用 `FOLIO_TEST_EXE` 指向打包后的 EXE，再执行 `pnpm test:native` 验证发行物。

## 预览版边界

这不是“所有笔记都绝对兼容”的承诺。编辑器使用 CodeMirror 的可视区域渲染；未改变的模式与近期标签复用预览 DOM，源码模式输入不后台重绘预览，滚动状态更新每帧合并。预览缓存最多保留 4 篇，按 HTML 长度约 4 MiB 估算淘汰（当前可见文档除外；并非实际内存硬上限）。阅读页面首次加载仍全量解析与布局，大型文档、大量公式 / 图表仍可能卡顿，尚未实现阅读虚拟化或独立解析 worker。复杂转义、HTML 和布局变化的定位会退回块级近似。原生运行时体积与内存高于轻量 WebView2 外壳。

安装包尚未代码签名，Windows 可能提示未知发布者；图标仍为运行时默认图标。当前验证以合成回归样本为主，尚未对所有个人课程笔记进行全面人工验收。建议先并行试用，不要删除原查看器。
