# 傅里叶分析

把信号拆成不同频率的正弦分量，是信号处理、偏微分方程和图像压缩的共同起点。本笔记整理连续傅里叶变换的定义、常用性质与离散实现。

## 定义

<a id="ft-def"></a>

**定义（傅里叶变换）。** 对可积函数 $f(t)$，其傅里叶变换与逆变换为

$$
\hat f(\omega) = \int_{-\infty}^{\infty} f(t)\, e^{-i\omega t}\, dt,
\qquad
f(t) = \frac{1}{2\pi} \int_{-\infty}^{\infty} \hat f(\omega)\, e^{i\omega t}\, d\omega .
$$

直观上，$\hat f(\omega)$ 衡量 $f$ 与频率为 $\omega$ 的复指数 $e^{i\omega t}$ 有多“相像”。

## 常用性质

| 性质 | 时域         | 频域                                          |
| ---- | ------------ | --------------------------------------------- |
| 线性 | $a f + b g$  | $a \hat f + b \hat g$                         |
| 平移 | $f(t - t_0)$ | $e^{-i\omega t_0} \hat f(\omega)$             |
| 缩放 | $f(a t)$     | $\frac{1}{\lvert a\rvert} \hat f(\omega / a)$ |
| 微分 | $f'(t)$      | $i\omega\, \hat f(\omega)$                    |
| 卷积 | $(f * g)(t)$ | $\hat f(\omega)\, \hat g(\omega)$             |

其中卷积性质最常用，详见 [卷积定理](卷积定理.md#证明思路)。

## Parseval 恒等式

<a id="parseval"></a>

能量在两个域中守恒：

$$
\int_{-\infty}^{\infty} \lvert f(t) \rvert^2 dt = \frac{1}{2\pi} \int_{-\infty}^{\infty} \lvert \hat f(\omega) \rvert^2 d\omega .
$$

> **提示**：在数值计算中，这条恒等式常被用来检查 FFT 的归一化是否正确。

## 离散实现

长度为 $N$ 的序列 $x_n$ 的离散傅里叶变换为 $X_k = \sum_{n=0}^{N-1} x_n e^{-2\pi i k n / N}$。直接计算需要 $O(N^2)$ 次运算，快速傅里叶变换（FFT）把它降到 $O(N \log N)$。

```python
import numpy as np

def dft(x):
    n = np.arange(len(x))
    k = n.reshape(-1, 1)
    return np.exp(-2j * np.pi * k * n / len(x)) @ x

signal = np.sin(2 * np.pi * 5 * np.linspace(0, 1, 256))
assert np.allclose(dft(signal), np.fft.fft(signal))
```

## 窗函数

有限长截断会带来频谱泄漏。常见窗函数的取舍：

| 窗函数   | 主瓣宽度 | 旁瓣衰减 | 适用场景           |
| -------- | -------- | -------- | ------------------ |
| 矩形窗   | 最窄     | 最差     | 瞬态、整周期信号   |
| 汉宁窗   | 中等     | 较好     | 通用频谱分析       |
| 布莱克曼 | 较宽     | 很好     | 需要抑制强干扰分量 |
