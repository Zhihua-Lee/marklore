# 采样定理

连续信号要以多快的速度采样，才能从样本中完整恢复？答案取决于它的频谱。

## 定理

<a id="sampling"></a>

**定理（Nyquist–Shannon）。** 若 $f$ 的 [傅里叶变换](傅里叶分析.md#ft-def) 在 $\lvert\omega\rvert > \Omega$ 时为零，则以间隔 $T \le \pi / \Omega$ 采样即可完整恢复 $f$：

$$
f(t) = \sum_{n=-\infty}^{\infty} f(nT)\, \operatorname{sinc}\!\left(\frac{t - nT}{T}\right).
$$

## 为什么成立

采样相当于乘上一串冲激；由 [卷积定理](卷积定理.md#theorem)，时域相乘对应频域卷积，频谱因此按 $2\pi / T$ 周期复制。只要复制件互不重叠，用一个低通滤波器就能取回原频谱。

## 混叠

采样过慢时，复制的频谱相互重叠，高频成分被误认为低频，这就是混叠。实践中先做抗混叠滤波，再采样。
