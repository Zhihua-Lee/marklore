# 使用指南

[返回 README](../README.md) · [开发与构建](development.md)

本指南说明桌面应用的日常操作。浏览器演示不具备原生文件访问、保存和导出能力。

## 打开笔记与笔记库

用 **打开文件** 选择一篇或多篇笔记，用 **打开文件夹** 将目录加入笔记库，或把 Markdown 文件从资源管理器拖入窗口。已打开的文件会切换到原标签，不覆盖其中的未保存内容。

笔记库按文件名筛选，包含未展开的子目录；这不是全文搜索。当前笔记所在目录会自动展开。其他程序（AI 工具、同步盘、资源管理器）在笔记库中新建、改名或删除笔记和文件夹时，文件树会自动更新，并保留已展开的文件夹；隐藏文件夹（如 `.git`）和非 Markdown 文件的变化不会触发刷新。也可以用刷新按钮手动重新读取目录。新建入口使用 `Ctrl+N`；关闭最后一个标签后返回起始页。

## 和 AI 一起维护知识库

Marklore 的笔记就是普通的 `.md` 文件，AI 工具可以直接读写。在 Marklore 中打开知识库文件夹，再在同一文件夹中运行 AI 工具（例如在该目录的终端中运行 `claude`），让它撰写、拆分、链接或整理笔记：

- 新建的笔记会自动出现在笔记库中；
- 已打开的笔记在磁盘上被修改后会自动重新渲染；
- 你有未保存的修改时，Marklore 会提示冲突，而不是覆盖草稿。

为了让 AI 写出的内容正确渲染，可以在知识库的 `AGENTS.md` 或 `CLAUDE.md` 中写明约定：一个主题一个文件；用相对链接连接笔记，可带标题锚点（如 `[卷积定理](卷积定理.md#定义)`）；行内公式写在 `$…$` 中，独立公式写成 `$$` 块，每个 `$$` 单独占一行；图片放在笔记旁的 `assets` 文件夹。

## 阅读和编辑

阅读、编辑、源码三种模式共享文档与草稿，分别使用 `Ctrl+1`、`Ctrl+2`、`Ctrl+3` 切换。阅读模式不显示编辑工具；编辑模式保留源码与预览双栏，分隔条可拖动调整宽度。

### 格式工具

源码编辑区提供标题、粗体、斜体、删除线、列表、引用、代码、公式、链接、图片、表格和分割线等操作。工具作用于选区或当前行，直接修改 Markdown，并支持撤销／重做。

在编辑模式的预览区划选文字，会出现浮动格式栏。普通文字及同一正文块内能准确映射源码的行内公式可以一起处理；公式按整体保留 LaTeX，不逐个修改显示字形。跨块选区、复杂 HTML 或无法精确映射的内容，应在源码区或块编辑器中修改。

阅读模式默认不显示格式栏，以免干扰阅读。在 `设置 → 批注 → 阅读模式中的格式栏` 中开启后，阅读模式中划选文字也会出现同样的格式栏，修改直接写入草稿、按 `Ctrl+S` 保存；此时双击选中一个词而不再跳转，`Alt`+双击仍跳到对应源码。

高亮与文字颜色按钮左键应用记忆颜色，右键或聚焦后按 `↓` 打开调色板。预设色适配深浅主题，自定义色保持指定值；颜色以标准内联 HTML 写入 Markdown，其他查看器需要允许内联 HTML 才能显示。

### 块级就地编辑

在编辑模式下，将鼠标移到预览正文块上，点击铅笔；也可聚焦预览区后按 `Alt+Enter`。只有当前块变成 Markdown 编辑区，其余正文继续保持渲染。

`Ctrl+Enter` 完成，`Esc` 取消该块本次编辑。输入会进入共享草稿和恢复记录，但仍需显式保存才写回文件。原始 HTML 块请使用源码区；块级编辑不是任意富文本的所见即所得转换。

### 正文与源码定位

阅读模式双击文字可进入编辑并定位对应源码；编辑器双击可定位预览。编辑模式在预览中双击选词时保留预览焦点，方便继续使用浮动格式栏，`Alt+双击` 可转向源码。

普通文字尽量精确定位，公式、图表和复杂 HTML 按源码块定位；公式显示字形与 LaTeX 命令并非逐字对应。

### 查找

`Ctrl+F` 在当前笔记的渲染正文中查找，`Enter`／`F3` 下一处，`Shift+Enter`／`Shift+F3` 上一处，`Esc` 关闭。查找栏的“源码”按钮把当前词交给编辑器的查找栏。

在编辑或源码模式下，`Ctrl+F` 打开编辑器右上角的查找栏：输入时即跳到光标之后的第一处，并显示“第几处/共几处”；`Aa`、<u>ab</u>、`.*` 分别切换区分大小写、全字匹配与正则表达式；点击左侧箭头展开替换，`Enter` 替换当前，`Ctrl+Alt+Enter` 全部替换。

### 复制为 Markdown

在阅读区选中内容后按 `Ctrl+C`，剪贴板中是这段内容对应的 **Markdown 源码**：公式保留 `$…$`，链接保留目标地址，粗体、表格、任务列表和标题前缀照原样保留。完整选中的行内格式带上标记，只选中一部分时去掉被截断的标记；公式和图片总是整体复制。在同一个代码块内复制时，复制的就是显示的代码。

需要粘贴到 Word、邮件等富文本编辑器时，用 `Ctrl+Shift+C` 复制渲染结果（带格式的 HTML 与干净的纯文本）。表格按视图排序后，跨行选区按显示内容复制。

## 标签与阅读导航

拖动标签调整顺序，标签过多时用滚轮或两侧箭头浏览。右键标签可刷新、在资源管理器显示原文件、关闭，或管理分组。

分组具有名称和颜色，可折叠、重命名或整体移动。折叠不关闭笔记，取消分组不删除文件。组内笔记通过链接派生的新标签和新建笔记继承来源组；已打开的目标保持原有分组，从文件树或文件选择器独立打开的笔记不自动归组。

侧栏目录用于定位标题，标题箭头与章节竖线用于折叠。用鼠标侧键或 `Alt+←`／`Alt+→` 沿标签切换、链接和目录跳转历史往返。标签栏左右箭头只滚动标签栏，不等于阅读历史按钮。

`设置 → 导航与滚动` 可选择全部笔记或仅当前笔记，并控制历史按钮是否显示。

`设置 → 导航与滚动 → 平滑滚动` 默认关闭。触控板和滚动条拖动的输入与屏幕刷新并不同步，60 Hz 屏幕上页面会一帧快一帧慢（Edge 等浏览器同样如此）；连续滚动鼠标滚轮时，每一格也各自加速、减速。开启后由 Marklore 按屏幕刷新逐帧移动页面：“仅触控板”只接管触控板；“触控板、滚轮与滚动条”还会让连续的滚轮汇成一段匀速滑动，并换用外观相同、拖动平滑的滚动条。速度更均匀，但跟手慢 1–3 帧。`Ctrl+滚轮`、横向滑动和链接预览等内部滚动区域不受影响。

## 公式、代码与表格

支持 Markdown 表格、任务列表、脚注、`<details>`、代码高亮、KaTeX 公式和 Mermaid 图。任务勾选在阅读区为只读，需要在编辑模式修改。

### 数学公式

可使用 `$...$`、`$$...$$`、`\(...\)`、`\[...\]` 和部分常用对齐环境。例如：

```markdown
行内公式：$E = mc^2$。

$$
\int_0^1 x^2\,dx = \frac{1}{3}
$$
```

表格公式中的数学竖线不会作为列分隔符。未知命令显示原式和错误提示，便于检查。KaTeX 不是完整 TeX 引擎，不支持所有 LaTeX 包、自动跨公式编号或任意自定义宏。

### 代码和图表

代码块显示语言标识，已支持的语言进行语法高亮，未知语言按纯文本显示。复制按钮复制完整代码文本，保留缩进与换行，不包含工具栏内容。

围栏语言标记为 `mermaid` 时渲染为图表，仍可复制其源代码。图表跟随页面主题，导出时转为静态图。

### 表格布局

`设置 → 表格` 可选择柔和卡片、简洁横线或经典网格，以及自适应内容或铺满正文两种宽度。

普通表格按实际文字和公式测量列宽；长文字换行，无法容纳的内容在表格内部横向滚动。合并单元格、嵌套表格或作者指定列宽的 HTML 表格保留原生布局。编辑器插入表格可选 1–12 列、1–30 行；`Tab`／`Shift+Tab` 在已有单元格间移动，跳过分隔行。

## 链接与悬浮预览

悬停本地 Markdown 链接约 350 毫秒，可在浮层阅读目标内容，不打开新标签。移入浮层后可以滚动、选中文字、展开章节和复制代码；点击“打开”才正式导航。底部字号设置独立于主阅读区，并会记住。

```markdown
[另一个笔记](other.md)
[某个标题](other.md#中文标题)
[行列位置](other.md#L40C5)
[带空格的路径](<Folder/Other note.md#heading>)
```

标题锚点使用小写 slug，空格替换为 `-`，保留中文；重复标题追加 `-1`、`-2`。也支持显式 HTML `id`。无法找到锚点时提示并显示文档开头。

目标笔记已打开且有修改时，预览优先显示草稿。悬浮预览仅访问已授权范围；越界链接须主动点击确认，或先将目录加入笔记库。网页不会在后台抓取或预览，点击后经确认交给系统浏览器。

键盘操作：`Tab` 聚焦链接显示预览，`F2` 进入浮层，`Esc` 关闭并返回链接。

### 反向链接与失效链接

Marklore 读取笔记库中所有笔记的链接，记下谁链接到谁、链接到哪个标题或锚点，以及链接所在的那句话；其他程序修改、新建或删除笔记后自动更新。

- 被其他笔记链接到的标题、定义或定理旁会出现一个小标记和引用次数；文首大标题旁的次数统计整篇笔记收到的全部链接。没有被引用的地方不显示任何东西。
- 悬停小标记显示引用浮窗：来源笔记、所在小节和引用的原句，链接部分高亮。点击一条打开来源笔记并定位到那个链接，`Alt+←` 返回；点击小标记可以固定浮窗，`Esc` 关闭。
- 指向本笔记中已不存在位置的链接，会让文首标记显示为虚线边框，浮窗中列为“不存在的位置”。
- 本笔记中指向不存在的笔记、标题或锚点的链接显示为红色虚线下划线，悬停可看到原因。

反向链接只统计笔记库（“打开文件夹”加入的文件夹）中的笔记；未保存的修改要保存后才会计入其他笔记。

**锚点**：在段落上方单独一行写 `<a id="erm"></a>`，就能用 `笔记.md#erm` 链接到这一段。段落以粗体开头（如 `**定义（ERM）。**`）时，粗体部分会作为它的名称。

**复制指向这里的链接**：在正文的标题、定义或段落上右键，选择“复制指向这里的链接”。标题直接使用它的锚点；已有锚点的段落沿用原锚点；没有锚点的段落会弹出对话框，锚点名称按段首粗体预填，可以修改，确认后在段落上方加入锚点（列表项则加在条目开头）并复制链接。新加的锚点在保存本笔记后才对其他笔记生效。复制的链接带有完整路径，在 Marklore 中粘贴到另一篇笔记时会自动换算成相对路径；粘贴回同一篇笔记时变为 `#锚点`。

在左侧笔记库的笔记上右键，选择“复制链接”，可复制指向整篇笔记的链接，粘贴时同样自动换算成相对路径。

**选择链接目标**：编辑工具栏的“插入链接”（`Ctrl+K`）和格式栏的“链接”输入框会列出笔记库中的笔记。输入笔记名的一部分即可筛选，也会列出名称匹配的标题和锚点；选中一篇笔记后列出它的全部标题和 ◇ 锚点，选中即填入 `笔记.md#锚点`。在格式栏中选中锚点会立即生效；输入以 `https://` 开头的网址时不显示建议。

**目录中的引用点**：`设置 → 布局与侧栏 → 目录中的引用点`。

- 关：目录只列标题。
- 被引用的位置（默认）：标题旁显示引用次数；被引用过的锚点段落以 ◇ 列在所属小节下。
- 所有锚点：列出所有用锚点标出的段落，包括还没有被引用的定义、定理。

## 图片与附件

图片可通过文件选择、剪贴板粘贴或拖入编辑区插入。应用将图片复制到笔记旁的 `assets` 目录，并写入相对路径；不移动或覆盖原图。未命名笔记须先保存。

一次最多插入 20 张图片，每张不超过 32 MB，总计不超过 64 MB。剪贴板像素转为 PNG，文件形式的 GIF 保留动画。撤销只删除 Markdown 引用，不自动删除附件；移动或分享笔记时请带上附件目录。

本地图片加载失败时显示原因和重试入口。超出笔记或笔记库目录的图片，可主动选择仅本次授权，或记住其所在目录及子目录；该授权不扩大 Markdown 文件或其他附件的访问范围。远程图片不会自动下载。

本地 Markdown／文本链接在应用内打开，受支持的 PDF、Office、图片、音视频和压缩包交给系统默认软件。可执行程序、脚本、快捷方式不会直接启动；未知类型需通过文件夹打开。UNC／网络共享链接暂不支持。

## 外观与布局

工具栏右侧的“设置”按钮（滑杆图标）打开设置：左侧按阅读排版、主题与语言、表格、布局与侧栏、导航与滚动、后台与系统分节，点击即跳到对应一节；每项设置占一行，改动立即生效。文件夹与目录可以分别放在左侧、右侧或隐藏；窄窗口下侧栏作为浮层，不挤占正文。

默认正文字体为 Literata，代码使用 JetBrains Mono，界面使用 Inter。中文优先使用本机 Noto Sans SC，缺少时回退微软雅黑；`设置 → 阅读排版 → 恢复书页排版` 恢复 Literata 与自然浓度，保留字号和布局。公式使用 KaTeX 字体。

界面支持中文与英文。`设置 → 主题与语言 → 界面语言` 默认“跟随系统”，也可固定为中文或 English；切换时先保存标签与草稿，再以新语言重新载入界面，托盘菜单与对话框同时切换。笔记内容不受影响。

主阅读区与链接预览的字号范围均为 50%–200%，两者独立。动画遵循系统减少动态效果设置。

窗口不使用系统标题栏：工具栏一直延伸到窗口边缘，空白处可拖动窗口、双击最大化。右端单独一组紧凑的窗口按钮依次为全屏、最小化、最大化／还原和关闭；全屏时只保留退出全屏与关闭。`F11` 切换全屏，`Ctrl+滚轮` 调整正文字号。

## 导出

保存按钮旁的导出菜单提供 PDF 和 HTML。导出使用当前标签的最新内容，包括未保存的草稿；不自动保存或修改 Markdown 原件。

折叠章节与 `<details>` 展开，公式完整渲染，Mermaid 转成静态图。导出保留所选表格样式和宽度；HTML 为可离线打开的单文件，嵌入样式、相关字体和已授权本地图片。PDF 使用浅色排版，GIF 在 PDF 中为静态画面。

中文仍依赖本机字体，远程图片不联网下载，无法嵌入的内容会提示。导出可能保留本地链接，分享前应检查路径及私人信息。

## 保存与恢复

`Ctrl+S` 保存，`Ctrl+Shift+S` 另存为。保存前检查磁盘版本，并通过同目录临时文件替换原件，保留覆盖前备份。外部程序修改已保存文档时自动刷新；存在未保存编辑时显示冲突处理，不静默覆盖草稿。

恢复草稿与标签状态写入本机 `session.json`，持续输入最迟约 5 秒触发一次；正常退出会等待写入。恢复记录不等于保存文件，异常断电仍可能丢失最近数秒输入。磁盘版本检查也不等于跨进程文件锁或云同步事务。

默认数据目录通常为 `%APPDATA%/Marklore`（改名前的 Folio Notes 使用 `%APPDATA%/folio-notes`，新版首次启动时自动迁移），包含明文草稿、文件路径和 `backups`。不要公开上传该目录；备份目前不自动过期，需要自行管理空间。应用本身不提供云同步、遥测或自动上传，OneDrive 等外部同步工具仍按各自规则运行。

**便携模式**：`设置 → 后台与系统 → 便携模式` 开启后，标签、草稿、最近文件、后台设置与备份保存在程序旁的 `data` 文件夹，适合把整个程序目录放在 U 盘中随身使用。开启时先保存当前状态，把上述数据复制过去并自动重启；浏览器内核的缓存仍留在用户目录，不占用 U 盘。停用时数据复制回用户目录，`data` 文件夹在下次启动时改名为 `data-disabled-日期` 保留，不会删除。程序目录不可写入（例如位于 Program Files）时无法开启。

可在启动前将 `FOLIO_DATA_DIR` 设为绝对路径，隔离配置和恢复数据；不要让多个运行中的实例共用一个数据目录。开发与测试用法见[开发指南](development.md)。

| 限制         | 当前范围         |
| ------------ | ---------------- |
| 同时打开标签 | 最多 100 个      |
| 单个文件     | 最大 32 MB       |
| 会话恢复数据 | 总大小上限 64 MB |

超限会报错，不静默截断草稿。大型草稿应及时保存。大量公式、图表或超长文档首次打开仍需要完整解析，近期预览复用和缓存不能消除所有开销。

## 后台与 Windows 集成

托盘可重新打开窗口、隐藏窗口或完全退出。`设置 → 后台与系统` 中，“关闭窗口后留在托盘”和“开机启动到托盘”默认关闭，须主动开启。

启用留在托盘后，关闭窗口只隐藏，不退出；完全退出请使用托盘菜单。隐藏前等待恢复草稿写入，但不自动保存 Markdown，后台仍占用内存。

注册 Markdown 支持只将本应用加入当前用户的候选应用。随后通过 Windows 默认应用设置选择 Marklore，不自动抢占默认关联，也不需要管理员权限。便携版移动或升级到新目录后，应从新版本更新注册与启动路径，再移除旧目录。

## 故障排查

| 现象                       | 检查方法                                                       |
| -------------------------- | -------------------------------------------------------------- |
| 浏览器中不能保存或访问文件 | 浏览器仅为 UI 演示，请构建后用 `pnpm start` 启动桌面应用。     |
| 复制 EXE 后无法运行        | 使用完整应用目录，保留 DLL、`resources`、`locales` 等文件。    |
| 图片打不开                 | 检查原文件及 `assets` 路径；仅在显示授权原因时使用授权入口。   |
| 文件被外部修改             | 使用冲突提示核对磁盘与草稿，不直接覆盖尚未保存的编辑。         |
| 公式出现错误               | 检查 KaTeX 支持的语法；未知命令旁会保留原式。                  |
| 很长的笔记首次打开较慢     | 大量公式和图表有解析与布局成本，当前没有任意长度无卡顿的保证。 |
| 退出后仍有进程             | 检查留在托盘设置，使用托盘的“退出 Marklore”。                  |

提交问题时附应用版本、复现步骤和最小示例。不要附真实私人笔记、恢复目录或未经清理的导出文件。
