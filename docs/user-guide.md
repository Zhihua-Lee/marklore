# 使用指南

[返回 README](../README.md) · [开发与构建](development.md)

本指南说明桌面应用的日常操作。浏览器演示不具备原生文件访问、保存和导出能力。

## 打开笔记与笔记库

用 **打开文件** 选择一篇或多篇笔记，用 **打开文件夹** 将目录加入笔记库，或把 Markdown 文件从资源管理器拖入窗口。已打开的文件会切换到原标签，不覆盖其中的未保存内容。

笔记库上方的搜索框（`Ctrl+Shift+F`）边输入边给出结果：文件名和正文一起搜索，每篇笔记只列一次，文件名和正文中的关键词都会高亮。搜索覆盖用“打开文件夹”加入笔记库的所有笔记（最多 5000 篇、每篇不超过 2 MB），不区分大小写，中文无需分词；空格分隔的几个词须同时出现在同一篇笔记中（文件名或正文均可），用英文引号括起的词组按整体匹配。排序时文件名命中的笔记在前，其次是标题中的命中，再按命中次数；最多显示 50 篇，每篇显示最多 3 处命中的章节和那一句，公式照常排版，片段不会从公式、代码或链接中间截断。当前笔记所在的文件夹若不在笔记库中，其中按文件名匹配的笔记会随后补在列表末尾。点击结果打开笔记并定位到该行，查找栏同时高亮这个词，`Enter` 继续跳到下一处；结果列表保留，可以接着打开下一条。在搜索框中按 `↓` 进入结果、`↑`／`↓` 在结果间移动，`Enter` 打开第一条。笔记在磁盘上改动后，结果会自动更新。若当前选中了一小段文字，按 `Ctrl+Shift+F` 会直接用它搜索。清空搜索框后回到文件树，当前笔记所在目录会自动展开。

笔记库很大时（例如用 SSHFS-Win 把服务器的整个家目录挂成盘符），读取会持续一段时间：已读到的笔记立即可以搜索，结果下方提示仍在读取，并随读取进度更新。Python／conda 环境、`node_modules`、`site-packages`、`__pycache__` 会自动跳过，`.txt` 文件不参与搜索。实验输出、数据等不放笔记的文件夹，可以在笔记库中右键选择“不参与搜索和反向链接”：它及其子文件夹变灰并标注“不参与搜索”，不再被读取；`设置 → 布局与侧栏 → 不参与搜索的文件夹` 列出全部排除项，点“恢复”即可重新加入。其他程序（AI 工具、同步盘、资源管理器）在笔记库中新建、改名或删除笔记和文件夹时，文件树会自动更新，并保留已展开的文件夹；隐藏文件夹（如 `.git`）和非 Markdown 文件的变化不会触发刷新。也可以用刷新按钮手动重新读取目录。新建入口使用 `Ctrl+N`；关闭最后一个标签后返回起始页。

### 目录文件决定顺序

文件树默认先列文件夹、再按名称列笔记。文件夹里若有目录文件 `_目录.md`（OneNote 导出时生成）或 `SUMMARY.md`，文件树改按它排列：目录文件本身排在最前，其后是它链接到的笔记和子文件夹，顺序与目录中的列表一致；列表中缩进在某篇笔记下的条目显示为它的子页，可以点左侧小三角折叠。目录文件是普通的 Markdown 列表，每项一个相对链接（如 `- [第一章](第一章.md)`，子文件夹写成 `子文件夹/` 或 `子文件夹/_目录.md`），缩进表示层级。目录里没有列出的笔记和文件夹按原来的方式排在后面，链接到不存在文件的条目会被忽略。

在这样的文件夹里拖动条目即可调整顺序：拖到另一条目的上沿或下沿放在它前面或后面，拖到笔记中间则成为它的子页；目录中没有的笔记拖进来会新加一项。拖动只改写目录文件中的列表，不移动文件，其余内容保持原样。键盘上，选中条目后按 `Alt+↑`／`Alt+↓` 与上一项或下一项交换位置。目录文件正在某个标签中编辑且未保存时，拖动不会改写它，请先保存。注意：OneNote 重新导出时会覆盖目录文件，在 Marklore 中调整的顺序也会随之被覆盖。

## 和 AI 一起维护知识库

Marklore 的笔记就是普通的 `.md` 文件，AI 工具可以直接读写。在 Marklore 中打开知识库文件夹，再在同一文件夹中运行 AI 工具（例如在该目录的终端中运行 `claude`），让它撰写、拆分、链接或整理笔记：

- 新建的笔记会自动出现在笔记库中；
- 已打开的笔记在磁盘上被修改后会自动重新渲染；
- 你有未保存的修改时，Marklore 会提示冲突，而不是覆盖草稿。

为了让 AI 写出的内容正确渲染，可以在知识库的 `AGENTS.md` 或 `CLAUDE.md` 中写明约定：一个主题一个文件；用相对链接连接笔记，可带标题锚点（如 `[卷积定理](卷积定理.md#定义)`）；行内公式写在 `$…$` 中，独立公式写成 `$$` 块，每个 `$$` 单独占一行；图片放在笔记旁的 `assets` 文件夹。

### 让 AI 提议修改，先预览再接受（MCP）

不想让 AI 直接改文件时，可以把 Marklore 作为 MCP 服务器加到 AI 工具里（Claude Code、Codex、Claude Desktop 等）。AI 只能读取你开放的笔记库，并且只能**提议**：修改要你在 Marklore 里预览、接受之后才会写入。

1. 打开 `设置 → AI 助手`，在“AI 可以读取的笔记库”中打开要开放的笔记库。没打开的笔记库，以及不参与搜索的文件夹、隐藏文件夹，AI 都读不到。
2. 在“连接 AI 助手”中点击对应工具的按钮复制配置：Claude Code 是一条在终端运行的命令；Codex 是一段粘贴到 `config.toml` 的配置；其他工具用 JSON。服务器就是 Marklore 程序本身，不联网，也不需要另装软件。移动 Marklore 的位置后要重新添加。
3. 在 AI 工具里正常提要求，例如“把《计划》里的截止日期改到周四”。

AI 提交提议后，工具栏会出现一个带数字的星形按钮，点击可列出所有提议。打开一条提议，笔记上方会出现提议条：

- **预览**：笔记按提议修改后的样子显示，改动的文字以浅色底标出，改动的段落左侧有一条竖线；删掉的段落在其后一段旁以虚线标出。预览时笔记只读。
- **源码对比**：以 diff 形式显示源码前后的差别。
- **接受并保存**：把修改写入笔记并保存，可以用 `Ctrl+Z` 一次撤销整条提议。笔记里有你自己未保存的修改时，按钮变为“接受到草稿”：AI 的修改写入草稿，不替你保存，按 `Ctrl+S` 时一起保存。
- **拒绝**：笔记不变。
- 提议之后笔记若被改动，AI 要改的原文已经不在，提议条会说明并只能关闭，AI 会收到原因，可以重新提议。

AI 也可以提议新建笔记：预览在一个新标签里，点击“接受并创建”后才写入文件。没有处理的提议两周后失效。

### 批注：和 AI 双向讨论

在已保存的笔记中选中一段文字，右键选择“添加批注…”（或按 `Ctrl+Alt+M`，也可以点工具栏的批注按钮）写下批注。批注过的文字带有赭色下划线；阅读模式中点击它会打开讨论卡片，可以回复、标为已解决或删除。AI 通过 MCP 读取你的批注（等待它回复的会被标出），可以回复、标为已解决，也可以自己在某段文字上发起批注；需要修改时，它会另外提一条修改提议。

批注和提议都保存在 Marklore 的用户数据目录（`ai` 文件夹）中，不写进笔记文件。笔记改动后，批注会按原文和上下文重新找到位置；原文被删掉的批注仍列在批注按钮里，并注明原文已改动。

## 阅读和编辑

阅读、编辑、源码三种模式共享文档与草稿，分别使用 `Ctrl+1`、`Ctrl+2`、`Ctrl+3` 切换。阅读模式不显示编辑工具。编辑模式直接在排好版的笔记上打字，切换阅读和编辑时正文位置不变；源码模式只显示 Markdown 源码。

### 在正文里编辑

编辑模式显示的就是读起来的样子，光标落在哪里就在哪里打字，不用切到源码。保存时只改动你改过的地方：没碰过的块逐字节保持原样，改过的块也尽量只改动打字的那几个字符。撤销、重做每个标签各自保留。

- 公式：点击公式、用方向键移进公式或按 `Enter`，公式在原处变成源码（如 `$x^2$`）；光标离开后重新排版。公式旁按 `Backspace`／`Delete` 先选中整个公式，再按一次删除。
- 列表：`Enter` 新起一项，空项再按 `Enter` 退出列表；有序列表自动续号；`Tab`／`Shift+Tab` 缩进或取消缩进。在段首输入 `# `（`## `、`### ` 等同理）、`- `、`1. `、`[ ] `、`> ` 后按空格，即变成标题、列表、任务或引用；只打符号不按空格时仍是普通文字。
- 一行只有 ` ```语言 `、`$` 或 `---` 时按 `Enter`，分别变成代码块、公式块或分割线。
- 表格：直接在单元格里打字；`↑`／`↓` 移到上方／下方单元格，在首行或末行时移出表格；`Tab`／`Shift+Tab` 移到后一个／前一个单元格，`Enter` 移到下方单元格（最后一行时新增一行）。右键菜单可以插入、删除行列和调整对齐。
- 链接：光标停在链接上，下方出现地址框，可以修改地址、打开或移除链接。`Ctrl+K` 给选中的文字加链接，按住 `Ctrl` 点击打开链接；把网址粘贴到选中的文字上也会变成链接。
- 图片：点击图片，下方的小框可以修改地址和说明文字，或删除图片。插入、粘贴或拖入的图片会复制到笔记旁的 `assets` 文件夹，放在光标处或拖放的位置。
- 折叠块（`<details>`）：默认折叠，点击标题前的小三角展开；标题和内容都可以直接修改，光标移进去时自动展开。
- 代码块按语言着色，可以直接修改。图表、注释等原始 HTML 显示为整体，点击即在原处显示源码，改完离开即恢复显示。
- 彩色文字、`<mark>` 高亮、下划线等行内 HTML 照常显示并可以直接修改，标签按原样写回。
- 行内代码：光标停在代码边上时，代码外圈出现细框表示接着打的字会进入代码；`←`／`→` 先在“代码内”和“代码外”之间切换，再继续移动。
- 表格、公式、代码块、图表在笔记末尾或彼此相邻时，方向键可以把光标停在两块之间（显示为横跨正文的一条线），打字即新起一段。方向键选中整个公式或图表时，它四周出现实线框。
- 笔记开头的属性（YAML front matter）显示为一行“属性”，点击即在原处显示源码修改。

## 打开笔记与笔记库

用 **打开文件** 选择一篇或多篇笔记，用 **打开文件夹** 将目录加入笔记库，或把 Markdown 文件从资源管理器拖入窗口。已打开的文件会切换到原标签，不覆盖其中的未保存内容。

笔记库上方的搜索框（`Ctrl+Shift+F`）边输入边给出结果：文件名和正文一起搜索，每篇笔记只列一次，文件名和正文中的关键词都会高亮。搜索覆盖用“打开文件夹”加入笔记库的所有笔记（最多 5000 篇、每篇不超过 2 MB），不区分大小写，中文无需分词；空格分隔的几个词须同时出现在同一篇笔记中（文件名或正文均可），用英文引号括起的词组按整体匹配。排序时文件名命中的笔记在前，其次是标题中的命中，再按命中次数；最多显示 50 篇，每篇显示最多 3 处命中的章节和那一句，公式照常排版，片段不会从公式、代码或链接中间截断。当前笔记所在的文件夹若不在笔记库中，其中按文件名匹配的笔记会随后补在列表末尾。点击结果打开笔记并定位到该行，查找栏同时高亮这个词，`Enter` 继续跳到下一处；结果列表保留，可以接着打开下一条。在搜索框中按 `↓` 进入结果、`↑`／`↓` 在结果间移动，`Enter` 打开第一条。笔记在磁盘上改动后，结果会自动更新。若当前选中了一小段文字，按 `Ctrl+Shift+F` 会直接用它搜索。清空搜索框后回到文件树，当前笔记所在目录会自动展开。

笔记库很大时（例如用 SSHFS-Win 把服务器的整个家目录挂成盘符），读取会持续一段时间：已读到的笔记立即可以搜索，结果下方提示仍在读取，并随读取进度更新。Python／conda 环境、`node_modules`、`site-packages`、`__pycache__` 会自动跳过，`.txt` 文件不参与搜索。实验输出、数据等不放笔记的文件夹，可以在笔记库中右键选择“不参与搜索和反向链接”：它及其子文件夹变灰并标注“不参与搜索”，不再被读取；`设置 → 布局与侧栏 → 不参与搜索的文件夹` 列出全部排除项，点“恢复”即可重新加入。其他程序（AI 工具、同步盘、资源管理器）在笔记库中新建、改名或删除笔记和文件夹时，文件树会自动更新，并保留已展开的文件夹；隐藏文件夹（如 `.git`）和非 Markdown 文件的变化不会触发刷新。也可以用刷新按钮手动重新读取目录。新建入口使用 `Ctrl+N`；关闭最后一个标签后返回起始页。

## 和 AI 一起维护知识库

Marklore 的笔记就是普通的 `.md` 文件，AI 工具可以直接读写。在 Marklore 中打开知识库文件夹，再在同一文件夹中运行 AI 工具（例如在该目录的终端中运行 `claude`），让它撰写、拆分、链接或整理笔记：

- 新建的笔记会自动出现在笔记库中；
- 已打开的笔记在磁盘上被修改后会自动重新渲染；
- 你有未保存的修改时，Marklore 会提示冲突，而不是覆盖草稿。

为了让 AI 写出的内容正确渲染，可以在知识库的 `AGENTS.md` 或 `CLAUDE.md` 中写明约定：一个主题一个文件；用相对链接连接笔记，可带标题锚点（如 `[卷积定理](卷积定理.md#定义)`）；行内公式写在 `$…$` 中，独立公式写成 `$$` 块，每个 `$$` 单独占一行；图片放在笔记旁的 `assets` 文件夹。

### 让 AI 提议修改，先预览再接受（MCP）

不想让 AI 直接改文件时，可以把 Marklore 作为 MCP 服务器加到 AI 工具里（Claude Code、Codex、Claude Desktop 等）。AI 只能读取你开放的笔记库，并且只能**提议**：修改要你在 Marklore 里预览、接受之后才会写入。

1. 打开 `设置 → AI 助手`，在“AI 可以读取的笔记库”中打开要开放的笔记库。没打开的笔记库，以及不参与搜索的文件夹、隐藏文件夹，AI 都读不到。
2. 在“连接 AI 助手”中点击对应工具的按钮复制配置：Claude Code 是一条在终端运行的命令；Codex 是一段粘贴到 `config.toml` 的配置；其他工具用 JSON。服务器就是 Marklore 程序本身，不联网，也不需要另装软件。移动 Marklore 的位置后要重新添加。
3. 在 AI 工具里正常提要求，例如“把《计划》里的截止日期改到周四”。

AI 提交提议后，工具栏会出现一个带数字的星形按钮，点击可列出所有提议。打开一条提议，笔记上方会出现提议条：

- **预览**：笔记按提议修改后的样子显示，改动的文字以浅色底标出，改动的段落左侧有一条竖线；删掉的段落在其后一段旁以虚线标出。预览时笔记只读。
- **源码对比**：以 diff 形式显示源码前后的差别。
- **接受并保存**：把修改写入笔记并保存，可以用 `Ctrl+Z` 一次撤销整条提议。笔记里有你自己未保存的修改时，按钮变为“接受到草稿”：AI 的修改写入草稿，不替你保存，按 `Ctrl+S` 时一起保存。
- **拒绝**：笔记不变。
- 提议之后笔记若被改动，AI 要改的原文已经不在，提议条会说明并只能关闭，AI 会收到原因，可以重新提议。

AI 也可以提议新建笔记：预览在一个新标签里，点击“接受并创建”后才写入文件。没有处理的提议两周后失效。

### 批注：和 AI 双向讨论

在已保存的笔记中选中一段文字，右键选择“添加批注…”（或按 `Ctrl+Alt+M`，也可以点工具栏的批注按钮）写下批注。批注过的文字带有赭色下划线；阅读模式中点击它会打开讨论卡片，可以回复、标为已解决或删除。AI 通过 MCP 读取你的批注（等待它回复的会被标出），可以回复、标为已解决，也可以自己在某段文字上发起批注；需要修改时，它会另外提一条修改提议。

批注和提议都保存在 Marklore 的用户数据目录（`ai` 文件夹）中，不写进笔记文件。笔记改动后，批注会按原文和上下文重新找到位置；原文被删掉的批注仍列在批注按钮里，并注明原文已改动。

### 格式工具

编辑模式和源码模式的顶部浮着一排格式工具：撤销／重做、段落样式、粗体、斜体、删除线、高亮、文字颜色、行内代码、列表、任务、引用、链接、图片、表格、代码块、公式块、行内公式和分割线。工具栏不占版面，切换模式时正文不会移动。显示源码栏时，工具作用于最后输入的那一栏。

在正文中选中文字，选区旁会浮出小工具栏：加粗、斜体、删除线、高亮、文字颜色、链接、行内代码和添加批注。

高亮与文字颜色按钮左键应用记忆颜色，右键或聚焦后按 `↓` 打开调色板。预设色适配深浅主题，自定义色保持指定值；颜色以标准内联 HTML 写入 Markdown，其他查看器需要允许内联 HTML 才能显示。

阅读模式默认不显示格式栏，以免干扰阅读。在 `设置 → 批注 → 阅读模式中的格式栏` 中开启后，阅读模式中划选文字也会出现格式栏，修改直接写入草稿、按 `Ctrl+S` 保存。

### 源码栏

在 `设置 → 编辑 → 编辑模式显示源码栏` 中开启后，编辑模式在正文旁同时显示 Markdown 源码，两边同步。关闭 `在渲染后的正文里编辑` 时，编辑模式改为源码与预览双栏。

极少数笔记含有编辑器还不能原样写回的写法；这时编辑模式会提示，并改用源码栏编辑这篇笔记，文件不会被改写。

### 正文与源码定位

阅读模式双击文字进入编辑模式，并在正文中选中这个词。源码栏显示时，在源码中双击可定位预览。

### 查找

阅读模式中 `Ctrl+F` 在渲染正文中查找，`Enter`／`F3` 下一处，`Shift+Enter`／`Shift+F3` 上一处，`Esc` 关闭；查找栏的“源码”按钮把当前词交给源码模式的查找栏。

在编辑或源码模式下，`Ctrl+F` 打开右上角的查找栏：输入时即跳到光标之后的第一处，并显示“第几处/共几处”；`Aa`、<u>ab</u>、`.*` 分别切换区分大小写、全字匹配与正则表达式；点击左侧箭头展开替换，`Enter` 替换当前，`Ctrl+Alt+Enter` 全部替换。

### 复制为 Markdown

在阅读区选中内容后按 `Ctrl+C`，剪贴板中是这段内容对应的 **Markdown 源码**：公式保留 `$…$`，链接保留目标地址，粗体、表格、任务列表和标题前缀照原样保留。完整选中的行内格式带上标记，只选中一部分时去掉被截断的标记；公式和图片总是整体复制。在同一个代码块内复制时，复制的就是显示的代码。

需要粘贴到 Word、邮件等富文本编辑器时，用 `Ctrl+Shift+C` 复制渲染结果（带格式的 HTML 与干净的纯文本）。表格按视图排序后，跨行选区按显示内容复制。

## 标签与阅读导航

拖动标签调整顺序。标签多时会逐渐变窄：窄标签省去扩展名，尽量多显示笔记名，末尾渐隐；实在放不下两个字时才只显示首字。当前标签始终保留足够宽度显示名称；仍放不下时用滚轮或两侧箭头浏览。

鼠标在标签上停留约半秒，下方会出现一张卡片：完整笔记名、文件路径、是否有未保存修改；其他标签的卡片还会显示这篇笔记上次停留位置的内容，不用切换过去就能看一眼。卡片出现后沿标签移动会立即跟随；点击、滚动标签栏或移开鼠标时卡片消失。悬停不会切换标签，也不改变阅读位置。中键点击标签即可关闭；右键标签可刷新、在资源管理器显示原文件、关闭，或管理分组。

分组具有名称和颜色，组名以同色小标签显示在组首，组内标签下方有同色细线；可折叠、重命名或整体移动。悬停组名可看到组内标签数；如希望折叠后直接在组名旁显示，可在 `设置 → 布局与侧栏 → 折叠的分组显示标签数` 中打开。折叠不关闭笔记，取消分组不删除文件。组内笔记通过链接派生的新标签和新建笔记继承来源组；已打开的目标保持原有分组，从文件树或文件选择器独立打开的笔记不自动归组。

侧栏目录用于定位标题，标题箭头与章节竖线用于折叠。用鼠标侧键或 `Alt+←`／`Alt+→` 沿标签切换、链接和目录跳转历史往返。标签栏左右箭头只滚动标签栏，不等于阅读历史按钮。

`设置 → 导航与滚动` 可选择全部笔记或仅当前笔记，并控制历史按钮是否显示。

`设置 → 导航与滚动 → 平滑滚动` 默认关闭。触控板和滚动条拖动的输入与屏幕刷新并不同步，60 Hz 屏幕上页面会一帧快一帧慢（Edge 等浏览器同样如此）；连续滚动鼠标滚轮时，每一格也各自加速、减速。开启后由 Marklore 按屏幕刷新逐帧移动页面：“仅触控板”只接管触控板；“触控板、滚轮与滚动条”还会让连续的滚轮汇成一段匀速滑动，并换用外观相同、拖动平滑的滚动条。速度更均匀，但跟手慢 1–3 帧。`Ctrl+滚轮`、横向滑动和链接预览等内部滚动区域不受影响。

## 公式、代码与表格

支持 Markdown 表格、任务列表、脚注、`<details>`、代码高亮、KaTeX 公式和 Mermaid 图。任务勾选在阅读区为只读，需要在编辑模式修改。

### 数学公式

可使用 `$...$`、`$$...$$`、`\(...\)`、`\[...\]` 和部分常用对齐环境。例如：

```markdown
行内公式：$E = mc^2$。

$$
\int_0^1 x^2\,dx = \frac{1}{3}
$$
```

表格公式中的数学竖线不会作为列分隔符。未知命令显示原式和错误提示，便于检查。KaTeX 不是完整 TeX 引擎，不支持所有 LaTeX 包、自动跨公式编号或任意自定义宏。

### 代码和图表

代码块显示语言标识，已支持的语言进行语法高亮，未知语言按纯文本显示。复制按钮复制完整代码文本，保留缩进与换行，不包含工具栏内容。

围栏语言标记为 `mermaid` 时渲染为图表，仍可复制其源代码。图表跟随页面主题，导出时转为静态图。

语言标记为 `diff` 或 `patch` 的代码块按行着色：增加的行为浅绿底，删除的行为浅红底，hunk 头与文件头颜色较淡。

### 其他格式：diff / patch

`设置 → 后台与系统 → 其他格式：diff / patch` 默认关闭。开启后，可以通过“打开”、拖入或文件夹列表打开 `.diff`、`.patch` 文件（统一 diff，包括 `git diff` 与 `git format-patch` 的输出）。

- 每个被改动的文件是一节，标题是文件路径和增删行数，新建、删除、重命名的文件会注明；目录按文件列出，可以逐节折叠。
- `format-patch` 的提交说明显示在最前面。
- 这类文件只读查看，没有格式工具；需要修改时用“源码”模式直接改原文。
- 它们不进入笔记库的索引、全文搜索与反向链接。

开启后，再点一次 `注册`（或已注册时自动）会把 Marklore 加入这两种文件的“打开方式”候选，单独作为“Diff / Patch 文件”类型，不抢占默认程序；关闭开关会移除这项注册。

### 表格布局

`设置 → 表格` 可选择柔和卡片、简洁横线或经典网格，以及自适应内容或铺满正文两种宽度。

普通表格按实际文字和公式测量列宽；长文字换行，无法容纳的内容在表格内部横向滚动。合并单元格、嵌套表格或作者指定列宽的 HTML 表格保留原生布局。编辑器插入表格可选 1–12 列、1–30 行；`Tab`／`Shift+Tab` 在已有单元格间移动，跳过分隔行。

## 链接与悬浮预览

悬停本地 Markdown 链接约 350 毫秒，可在浮层阅读目标内容，不打开新标签。移入浮层后可以滚动、选中文字、展开章节和复制代码；点击“打开”才正式导航。底部字号设置独立于主阅读区，并会记住。

```markdown
[另一个笔记](other.md)
[某个标题](other.md#中文标题)
[行列位置](other.md#L40C5)
[带空格的路径](<Folder/Other note.md#heading>)
```

标题锚点使用小写 slug，空格替换为 `-`，保留中文；重复标题追加 `-1`、`-2`。也支持显式 HTML `id`。无法找到锚点时提示并显示文档开头。

目标笔记已打开且有修改时，预览优先显示草稿。悬浮预览仅访问已授权范围；越界链接须主动点击确认，或先将目录加入笔记库。网页不会在后台抓取或预览，点击后经确认交给系统浏览器。

键盘操作：`Tab` 聚焦链接显示预览，`F2` 进入浮层，`Esc` 关闭并返回链接。

### 反向链接与失效链接

Marklore 读取笔记库中所有笔记的链接，记下谁链接到谁、链接到哪个标题或锚点，以及链接所在的那句话；其他程序修改、新建或删除笔记后自动更新。

- 被其他笔记链接到的标题、定义或定理旁会出现一个小标记和引用次数；文首大标题旁的次数统计整篇笔记收到的全部链接。没有被引用的地方不显示任何东西。
- 悬停小标记显示引用浮窗：来源笔记、所在小节和引用的原句，链接部分高亮。点击一条打开来源笔记并定位到那个链接，`Alt+←` 返回；点击小标记可以固定浮窗，`Esc` 关闭。
- 指向本笔记中已不存在位置的链接，会让文首标记显示为虚线边框，浮窗中列为“不存在的位置”。
- 本笔记中指向不存在的笔记、标题或锚点的链接显示为红色虚线下划线，悬停可看到原因。

反向链接只统计笔记库（“打开文件夹”加入的文件夹）中的笔记；未保存的修改要保存后才会计入其他笔记。

**锚点**：在段落上方单独一行写 `<a id="erm"></a>`，就能用 `笔记.md#erm` 链接到这一段。段落以粗体开头（如 `**定义（ERM）。**`）时，粗体部分会作为它的名称。

**复制指向这里的链接**：在正文的标题、定义或段落上右键，选择“复制指向这里的链接”。标题直接使用它的锚点；已有锚点的段落沿用原锚点；没有锚点的段落会弹出对话框，锚点名称按段首粗体预填，可以修改，确认后在段落上方加入锚点（列表项则加在条目开头）并复制链接。新加的锚点在保存本笔记后才对其他笔记生效。复制的链接带有完整路径，在 Marklore 中粘贴到另一篇笔记时会自动换算成相对路径；粘贴回同一篇笔记时变为 `#锚点`。

在左侧笔记库的笔记上右键，选择“复制链接”，可复制指向整篇笔记的链接，粘贴时同样自动换算成相对路径。

**选择链接目标**：编辑工具栏的“插入链接”（`Ctrl+K`）和格式栏的“链接”输入框会列出笔记库中的笔记。输入笔记名的一部分即可筛选，也会列出名称匹配的标题和锚点；选中一篇笔记后列出它的全部标题和 ◇ 锚点，选中即填入 `笔记.md#锚点`。在格式栏中选中锚点会立即生效；输入以 `https://` 开头的网址时不显示建议。

**目录中的引用点**：`设置 → 布局与侧栏 → 目录中的引用点`。

- 关：目录只列标题。
- 被引用的位置（默认）：标题旁显示引用次数；被引用过的锚点段落以 ◇ 列在所属小节下。
- 所有锚点：列出所有用锚点标出的段落，包括还没有被引用的定义、定理。

## 图片与附件

图片可通过文件选择、剪贴板粘贴或拖入编辑区插入。应用将图片复制到笔记旁的 `assets` 目录，并写入相对路径；不移动或覆盖原图。未命名笔记须先保存。

一次最多插入 20 张图片，每张不超过 32 MB，总计不超过 64 MB。剪贴板像素转为 PNG，文件形式的 GIF 保留动画。撤销只删除 Markdown 引用，不自动删除附件；移动或分享笔记时请带上附件目录。

本地图片加载失败时显示原因和重试入口。超出笔记或笔记库目录的图片，可主动选择仅本次授权，或记住其所在目录及子目录；该授权不扩大 Markdown 文件或其他附件的访问范围。远程图片不会自动下载。

本地 Markdown／文本链接在应用内打开，受支持的 PDF、Office、图片、音视频和压缩包交给系统默认软件。可执行程序、脚本、快捷方式不会直接启动；未知类型需通过文件夹打开。UNC／网络共享链接暂不支持。

## 外观与布局

工具栏右侧的“设置”按钮（滑杆图标）打开设置：左侧按阅读排版、主题与语言、表格、布局与侧栏、导航与滚动、后台与系统分节，点击即跳到对应一节；每项设置占一行，改动立即生效。文件夹与目录可以分别放在左侧、右侧或隐藏；窄窗口下侧栏作为浮层，不挤占正文。

默认正文字体为 Literata，代码使用 JetBrains Mono，界面使用 Inter。中文优先使用本机 Noto Sans SC，缺少时回退微软雅黑；`设置 → 阅读排版 → 恢复书页排版` 恢复 Literata 与自然浓度，保留字号和布局。公式使用 KaTeX 字体。

界面支持中文与英文。`设置 → 主题与语言 → 界面语言` 默认“跟随系统”，也可固定为中文或 English；切换时先保存标签与草稿，再以新语言重新载入界面，托盘菜单与对话框同时切换。笔记内容不受影响。

笔记开头的属性（YAML front matter，如 OneNote 导出页的 `title`、`modified`）在阅读模式中显示为一行“属性 · 标题 · 修改时间”，点击展开全部字段，目录中不出现。

`设置 → 阅读排版 → 中文旁的粗体与斜体` 开启后，`**定义：**其中` 这样以标点收尾、紧接中文的粗体也显示为粗体（CommonMark 规定这种写法不算粗体）。文件本身不变；其他严格遵循 CommonMark 的软件仍会显示星号。

主阅读区与链接预览的字号范围均为 50%–200%，两者独立。动画遵循系统减少动态效果设置。

窗口不使用系统标题栏：工具栏一直延伸到窗口边缘，空白处可拖动窗口、双击最大化。右端单独一组紧凑的窗口按钮依次为全屏、最小化、最大化／还原和关闭；全屏时只保留退出全屏与关闭。`F11` 切换全屏，`Ctrl+滚轮` 调整正文字号。

## 导出

保存按钮旁的导出菜单提供 PDF 和 HTML。导出使用当前标签的最新内容，包括未保存的草稿；不自动保存或修改 Markdown 原件。

折叠章节与 `<details>` 展开，公式完整渲染，Mermaid 转成静态图。导出保留所选表格样式和宽度；HTML 为可离线打开的单文件，嵌入样式、相关字体和已授权本地图片。PDF 使用浅色排版，GIF 在 PDF 中为静态画面。

目录：

- PDF 总是带书签，按标题层级嵌套，在阅读器的书签或大纲面板中可以点击跳转。标题中的公式在书签里显示为普通字符，例如 `F{f}(ω)`；上下标会被压平（`x²` 显示为 `x2`）。
- HTML 默认在页面左侧列出标题，点击即跳到对应位置；点"目录"可以收起，收起后正文占满宽度，再点一次展开。窄屏时目录在正文上方，打印时不显示。可在 `设置 → 导出 → HTML 附带目录` 中关闭。只有一个标题时不生成目录。

链接：网址和邮件链接在 HTML 和 PDF 中都可以点击，显示为链接色。指向其他笔记或本地文件的链接在 PDF 中只保留文字（独立的 PDF 无法打开它们）；HTML 保留这些相对链接，与笔记放在同一文件夹时仍然有效。

中文仍依赖本机字体，远程图片不联网下载，无法嵌入的内容会提示。导出可能保留本地链接，分享前应检查路径及私人信息。

## 保存与恢复

`Ctrl+S` 保存，`Ctrl+Shift+S` 另存为。保存前检查磁盘版本，并通过同目录临时文件替换原件，保留覆盖前备份。外部程序修改已保存文档时自动刷新；存在未保存编辑时显示冲突处理，不静默覆盖草稿。

恢复草稿与标签状态写入本机 `session.json`，持续输入最迟约 5 秒触发一次；正常退出会等待写入。恢复记录不等于保存文件，异常断电仍可能丢失最近数秒输入。磁盘版本检查也不等于跨进程文件锁或云同步事务。

默认数据目录通常为 `%APPDATA%/Marklore`（改名前的 Folio Notes 使用 `%APPDATA%/folio-notes`，新版首次启动时自动迁移），包含明文草稿、文件路径和 `backups`。不要公开上传该目录；备份目前不自动过期，需要自行管理空间。应用本身不提供云同步、遥测或自动上传，OneDrive 等外部同步工具仍按各自规则运行。

**便携模式**：`设置 → 后台与系统 → 便携模式` 开启后，标签、草稿、最近文件、后台设置与备份保存在程序旁的 `data` 文件夹，适合把整个程序目录放在 U 盘中随身使用。开启时先保存当前状态，把上述数据复制过去并自动重启；浏览器内核的缓存仍留在用户目录，不占用 U 盘。停用时数据复制回用户目录，`data` 文件夹在下次启动时改名为 `data-disabled-日期` 保留，不会删除。程序目录不可写入（例如位于 Program Files）时无法开启。安装版不提供便携模式：升级和卸载会替换整个程序目录，放在其中的数据会丢失；需要随身使用请下载压缩包版。

可在启动前将 `FOLIO_DATA_DIR` 设为绝对路径，隔离配置和恢复数据；不要让多个运行中的实例共用一个数据目录。开发与测试用法见[开发指南](development.md)。

| 限制         | 当前范围         |
| ------------ | ---------------- |
| 同时打开标签 | 最多 100 个      |
| 单个文件     | 最大 32 MB       |
| 会话恢复数据 | 总大小上限 64 MB |

超限会报错，不静默截断草稿。大型草稿应及时保存。大量公式、图表或超长文档首次打开仍需要完整解析，近期预览复用和缓存不能消除所有开销。

## 后台与 Windows 集成

托盘可重新打开窗口、隐藏窗口或完全退出。`设置 → 后台与系统` 中，“关闭窗口后留在托盘”和“开机启动到托盘”默认关闭，须主动开启。

启用留在托盘后，关闭窗口只隐藏，不退出；完全退出请使用托盘菜单。隐藏前等待恢复草稿写入，但不自动保存 Markdown，后台仍占用内存。

注册 Markdown 支持只将本应用加入当前用户的候选应用，不自动抢占默认关联，也不需要管理员权限。Windows 不允许程序自己设为默认应用，需要你确认一次：点“默认应用…”，Windows 10 会弹出“你要如何打开这个文件？”，选 Marklore 并勾选“始终使用此应用打开 .md 文件”；Windows 11 会打开 Marklore 的默认应用设置页。程序搬到新目录后，应从新目录的程序更新注册与启动路径，再移除旧目录。卸载安装版时会一并移除指向它的注册与开机启动。

### 更新

`设置 → 后台与系统 → 版本` 显示当前版本。点“检查更新”向 GitHub 查询最新发布；有新版本时点“更新到 vX.Y.Z”：Marklore 下载新版本，按发布中的 `SHA256SUMS` 校验，保存标签和草稿后退出，换上新文件并自动重新打开。“更新说明”打开该版本的发布页。

- 安装版运行新的安装包，装回原目录；压缩包版（包括便携模式）直接覆盖程序目录中的文件，`data` 文件夹原样保留。两种方式程序路径都不变，文件关联和开机启动无需重新设置。
- 程序目录不可写入时（例如压缩包版放在 Program Files），只提示新版本，请从发布页下载。
- “启动时检查更新”默认关闭；开启后每次启动查询一次，有新版本时提示，不会自动下载。除检查和下载更新外，Marklore 不访问网络。
- macOS 版目前只提示新版本，需从发布页下载。

| 图片打不开                 | 检查原文件及 `assets` 路径；仅在显示授权原因时使用授权入口。   |
| 文件被外部修改             | 使用冲突提示核对磁盘与草稿，不直接覆盖尚未保存的编辑。         |
| 公式出现错误               | 检查 KaTeX 支持的语法；未知命令旁会保留原式。                  |
| 很长的笔记首次打开较慢     | 大量公式和图表有解析与布局成本，当前没有任意长度无卡顿的保证。 |
| 退出后仍有进程             | 检查留在托盘设置，使用托盘的“退出 Marklore”。                  |

提交问题时附应用版本、复现步骤和最小示例。不要附真实私人笔记、恢复目录或未经清理的导出文件。
