# v0.1.30 find hands off to the editor's search

## Changes

The reading-mode find bar gains a "源码" button: it switches to edit mode and
opens CodeMirror's search panel with the current query, where regex, case,
whole-word and replace already exist. `@codemirror/search` (6.7.2, already
bundled through `basicSetup`) became a direct dependency so the query is set
on the same module instance; the startup entry chunk stays at 867 KB.

The `licenses` script was renamed to `notices`: pnpm's built-in `licenses`
command shadowed it, so `pnpm dist` and the CI notices check had never run
`tools/licenses.mjs`. CI now regenerates the notices (155 packages) and finds
no difference.

## Automated checks

All 59 unit tests and 147 browser cases (Edge; default and reduced-motion
projects) pass, including a case that the query lands in the editor's search
field. GitHub Actions accepted the hand-edited lockfile with
`--frozen-lockfile`. Format check and Vite build pass.

## Manual/native checks

The packaged v0.1.30 build passes all nine native suites. The smoke suite's
hover-preview step failed once while a real pointer crossed the test window
(trusted pointer events recorded) and passed on rerun. Only synthetic notes
and isolated profiles were used.

## Limits

Physical mouse hardware was not exercised.
