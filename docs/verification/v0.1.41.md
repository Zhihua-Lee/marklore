# v0.1.41 English interface, portable mode, new Settings, clearer selected tab

v0.1.37 to v0.1.40 were built only locally for testing and not published;
their changes are included here.

## Changes

- **English interface.**
  - The language follows the system (zh\* → Chinese, otherwise English)
    unless chosen in `设置 → 主题与语言 → 界面语言`.
  - A change takes effect at once. The page reloads itself; the navigation
    guard used to block that reload, so earlier builds needed a restart.
    Menus, tray and jump list are rebuilt.
  - The Chinese text is the key. `tools/i18n-check.mjs` fails on untranslated
    literals and on placeholder mismatches; it reports 518 keys.
  - README.md is now English, with English screenshots, animations and a
    sample notebook. The Chinese README is README.zh-CN.md.
- **Portable mode** (`设置 → 后台与系统 → 便携模式`).
  - Folio's own files (session, recent files, tray settings, backups) live in
    a `data` folder beside the program. Chromium's caches stay in the user
    profile.
  - Enabling copies the data to a staged folder, renames it into place and
    restarts, so a failed copy never switches modes.
  - Disabling copies the data back. The folder is renamed to
    `data-disabled-<date>` at the next start and is never deleted.
- **Settings redesign.**
  - A fixed title bar with a close button.
  - Section links on the left, with the current section marked while
    scrolling; on a narrow window they sit in a row above the pane.
  - One setting per row: name on the left, control on the right. Tray,
    startup and portable mode are switches.
  - The scattered hints and the "更改立即生效" note are gone.
- **Selected tab.**
  - A green tab group read like the green selected tab. An older, more
    specific rule also kept the accent tint on ungrouped tabs, so v0.1.40's
    first fix reached only grouped tabs.
  - The selected tab now has no hue: it is the one bright card in the strip,
    with a hairline edge, a soft shadow and a bold label. Only groups are
    coloured; a grouped selected tab keeps its group's outline.
  - Tabs no longer fade for 180 ms between states.

## Automated checks

All 67 unit tests and 164 browser cases (Edge; default and reduced-motion
projects) pass. New cases cover:

- the English interface, with no Chinese left in toolbar, edit tools, find
  bar, Settings or start page;
- the i18n check itself;
- Settings section links, the fixed title bar, no sideways scrolling, and the
  narrow layout;
- the selected tab: the same neutral card in and out of a group, bold, no
  transition. This case fails on the v0.1.40 CSS.
- portable-mode file handling (unit).

## Manual/native checks

The packaged v0.1.41 build passes all 11 native suites. Two are new:

- `native-language`: switches Chinese → English → Chinese from Settings,
  checks the page and the menu bar, and fails without the reload fix.
- `native-portable`: runs the enable → restart → disable → restart round trip
  on a copy of the packaged app with a stand-in profile. It needed one rerun
  on v0.1.40, before it was changed to reach the switch through the section
  link.

The tab strip was inspected in screenshots in both themes, with the selected
tab inside a green group and outside it.

## Limits

- The English text was reviewed by reading, not by a native speaker.
- Portable mode was exercised only on a local disk, not on a USB drive or a
  read-only folder.
