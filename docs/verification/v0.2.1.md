# v0.2.1 library follows the disk, annotation in Read mode, a new README

## Changes

- **The library follows the disk.** The folder tree used to change only on
  the refresh button, so notes that an AI agent or a sync tool created in the
  library stayed invisible.
  - Each library folder now has one recursive watcher. Creating, renaming or
    deleting a note or folder refreshes the tree after 400 ms.
  - Edits, hidden folders (`.git`, `.obsidian`), `node_modules` and other
    file types are ignored.
  - The refresh keeps the folders the reader opened and the scroll position.
    With a filter in use, the search runs again.
- **Annotation in Read mode, as an option.** `Settings → Annotation → Format
bar in Read mode` is off by default.
  - When on, selecting text in Read mode shows the same format bar as Edit
    mode's preview (bold, italic, strikethrough, highlight, color, link,
    code). Changes go to the draft and `Ctrl+S` saves them.
  - Double-clicking a word selects it instead of opening the editor;
    `Alt`+double-click still goes to the source.
- **Settings sidebar.** A clicked section stays marked while it is in view.
  The short new last section had taken the mark once the pane scrolled to
  its end.
- **README.**
  - It now opens with the project's idea: AI drafts, you refine and mark up;
    notes are plain files.
  - A section on working with an AI agent, with conventions for `AGENTS.md`
    and `CLAUDE.md`.
  - New demos: `agent.gif`, and `annotate.gif` recorded in Read mode.
    `edit.gif` was re-recorded to show the preview following typing. All
    media are regenerated in both languages.
  - The user guide covers the AI workflow, the live library and the option.

## Automated checks

All 74 unit tests and 170 browser cases (Edge; default and reduced-motion
projects) pass. New cases cover:

- which file-system changes refresh the tree; the watchers following the
  library folders; debouncing; a real note written into a temporary folder;
- the tree refresh keeping an open folder;
- the Read-mode option: off by default, on from Settings, a highlight saved
  as `<mark>`, double-click staying in Read mode, `Alt`+double-click opening
  Edit mode.

## Manual/native checks

The packaged v0.2.1 build passes all 12 native suites, with windows shown
inactive. The new `native-library.mjs` checks, in the real app:

- a note written and then renamed by another process appears in the tree;
- the folder the reader opened stays open;
- an open note re-renders as that process extends it.

The README media were inspected frame by frame:

- the agent demo shows the new file in the tree, then each step rendered;
- the edit demo shows the preview catching up during typing;
- the annotate demo shows Read mode, then the marks in the Edit-mode source.

## Limits

- The library watcher relies on recursive `fs.watch`, which Windows
  supports. On network drives that do not report changes, the refresh button
  is still needed.
- The README media script writes the agent's steps itself; no real agent was
  run for the recording.
