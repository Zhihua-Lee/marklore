# v0.2.2 backlinks in place, links to anchors, a format bar across elements

## Changes

- **Backlinks where the text is.** The library is indexed for links. A
  heading or anchored block that other notes link to gets a count badge;
  hovering it opens a card with each source's surrounding text (math
  rendered), and clicking an entry opens the source at the link.
  - Links to a missing note or anchor are marked as broken.
  - The index follows the library watcher, so a note written by another
    program updates the counts.
- **Anchors in the outline.** `Settings → Layout & sidebars → Anchors in the
outline` offers off, linked places (the default) and all anchors. Anchored
  blocks that are not headings appear under their section with a count.
- **Linking without typing paths.**
  - Right-click in the reader: `Copy link to here` copies a link to the
    heading, or adds a standard `<a id>` anchor above the block first.
  - Right-click a note in the library: `Copy link`.
  - Link fields (the insert-link dialog and the format bar) suggest notes,
    then that note's headings and anchors.
  - Pasting a copied link into another note writes a relative path, or
    `#id` within the same note.
- **Format bar across elements.** A selection that crosses links, inline
  code, emphasis, colored text or several blocks now shows the bar. Each
  block is formatted in one undo step; code and formulas are taken whole;
  Link and Code explain why they are unavailable when they are.
- **Faster previews.** Link previews render formulas progressively and
  reuse recent renders; math and highlighting load while idle. With a
  237-formula note, the first preview went from 1285 ms to 183 ms and a
  repeat from 264 ms to 22 ms. The backlinks card no longer closes by
  itself on first hover.
- **README, guide and sample notebooks** cover backlinks, anchors and link
  tools; all media were re-recorded in both languages.

## Automated checks

All 78 unit tests and 186 browser cases (Edge; default and reduced-motion
projects) pass. New cases cover:

- link parsing, anchors, snippets and status; the index following changes;
- badges, the card, broken links and the outline modes;
- copying a link here (heading, new anchor, taken names), copying a note's
  link, the link picker and pasted links;
- selections across links, code, emphasis, colored text and blocks.

## Manual/native checks

The packaged v0.2.2 build passes all 13 native suites, with windows shown
inactive. The new `native-backlinks.mjs` checks counts from the real index,
a note written by another program adding to them, the card opening the
source, and broken links.

The README media were inspected: the overview shows anchors with counts in
the outline, and the backlinks demo opens the card and follows an entry.

## Limits

- Only the main editor converts pasted `file:///` links; the block editor
  pastes them as they are.
- A new anchor counts for backlinks once the note is saved.
- Unlinked mentions (text that names a note without linking) are not shown.
