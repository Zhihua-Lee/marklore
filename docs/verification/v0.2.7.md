# v0.2.7 nothing jumps while editing; foldable contents and working links in exports

## Changes

- **A double click in Read mode keeps the clicked text in place.**
  - Before, switching to Edit moved the clicked paragraph to 80 px below the
    top: on a long note, a jump of most of a screen under the pointer.
  - Now the paragraph stays where it was on screen (within 1.5 px).
- **Block editing in place.**
  - Before, opening a paragraph for editing put a tool bar above it and a
    button row below it, pushing the text below down by 114 px. Done or Esc
    also left the block a pixel or two higher each time.
  - Now the source takes the block's place, with the same margins, font
    and line height. A faint tint marks it; it reaches past the block's edges
    without taking room.
  - The tools (formatting, Cancel, Done) float above the block like the
    selection tools, or below it near the top of the window. They take no
    room in the page.
  - A table inside its scroll box is edited as a whole, so the tools are no
    longer clipped by the box.
  - Done and Esc return the block exactly to where it was.
- **Contents in an HTML export fold away.**
  - The list beside the text is a disclosure ("目录"), open by default.
  - On a wide screen it folds into a small pill at the edge; on a narrow one,
    into its title above the text.
  - It still runs no script.
- **Links in a PDF export.**
  - Web, mail and phone links now keep their colour and stay clickable.
    Before, a print rule coloured them as plain text.
  - Links to other notes or local files cannot work in a PDF, so they are
    written as plain text instead of pointing nowhere.
  - HTML exports keep every link as it was.

## Automated checks

All 114 unit tests and 209 browser cases (Edge; default and reduced-motion
projects) pass. New cases:

- `no-jump.spec.js`:
  - a double click in Read mode keeps the paragraph within 1.5 px (it moved
    190 px on v0.2.6 code);
  - opening a paragraph for editing leaves the next paragraph in place
    (114 px on v0.2.6 code);
  - the tools float;
  - Done and Esc each return the block within 1 px.
- `export-toc.spec.js`: the HTML list folds and is titled "目录".

## Manual/native checks

The packaged v0.2.7 build passes all 14 native suites, with windows shown
inactive. `native-export` now also checks:

- the PDF's link to a web page is kept;
- a link to another note is not written into the PDF;
- the HTML keeps the relative link;
- the HTML contents fold.

`tools/installer-check.ps1` passes all checks, and the reader's Open with
entries are unchanged afterwards.

Screenshots of block editing were inspected in the light and dark themes,
for a paragraph and a code block.

## Limits

- Switching from Read to Edit with the toolbar still moves the text by about
  11 px, because the two modes lay out the note differently.
