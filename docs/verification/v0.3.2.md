# v0.3.2 input methods, default app on Windows 10, source-pane heights

## Changes

- **Input methods keep composing.** While an input method composes
  (`src/composing.js`), background work that changes the page waits until the
  composition ends: formula backfill, table widths, Mermaid insertion,
  broken-link marks, hover marks and memory release. Windows tells the input
  method about text changes near its composition, and Sogou Pinyin then ended
  it halfway (user report). Broken-link marks now change only the links whose
  state changed.
- **Default app on Windows 10.** Settings → Default app… opens the "How do
  you want to open this file?" dialog for a sample `.md` file (Windows 10 has
  no Default apps page for one app). Windows 11 still opens Marklore's own
  Default apps page.
- **Source pane scrollbar.** CodeMirror estimates the height of lines it has
  not drawn; wrapped lines (Chinese most) came out 19–46% short, so the
  scrollbar shrank and jumped while scrolling. `src/editor-heights.js`
  measures every line in idle slices and keeps the top line where it was;
  the estimate is now within 3%.
- **README.** Both READMEs repeated their first 95 lines inside the
  direct-editing paragraph (a `$` in a replacement in 686afba); fixed.

## Automated checks

All 125 unit tests and 230 browser cases (Edge; default and reduced-motion
projects) pass.

- New browser case in `direct-edit.spec.js`: composing (CDP
  `Input.imeSetComposition`) in a 600-line note with formulas and links while
  scrolling changes nothing else in the page, the committed text lands in the
  source, and the deferred formulas are typeset afterwards. Without the fix
  the page changed 40 times during the composition.
- Unit tests: the Windows 10 default-app dialog (rundll32 `OpenAs_RunDLL` on
  the sample file); the native background suite records the launch instead of
  opening the dialog.
- Source-pane heights, measured with a probe (`.local/cm-stay.mjs`): on an
  1,800-line note, the user guide and a table-heavy note, the line at the top
  stays at the same position while the heights are measured.

## Manual/native checks

The packaged v0.3.2 build passes all 16 native suites, with windows shown
inactive, including two in-app updates of a portable copy (whole zip, then
app files).

`tools/installer-check.ps1 -Newer` passes with a v0.3.3 test setup (0
failed): the installed v0.3.2 is updated in the app; the file association and
the startup entry are kept. The reader's Open with entries are unchanged
afterwards.

## Limits

- Input methods are tested through CDP composition events, not with Sogou
  Pinyin itself.
- The Windows 10 dialog was not opened on the test machine (it would take the
  foreground).
- The source-pane measuring uses CodeMirror's internal `view.measure()`; if a
  CodeMirror update removes it, the pane falls back to estimates.
