# v0.3.5 direct editing: formulas open in place, caret stays in its paragraph

## Changes

Prompted by an outside review of direct editing; every point was reproduced
in a headless probe first. All but one were confirmed: "_" inside an unclosed
"$" never became italics (an intraword "_" does not open emphasis); "*" is
guarded anyway.

- **Formulas open in place.** While the caret is inside a formula's source,
  the render emits that formula as its source text (`renderMarkdown({ open })`:
  `.formula-source` inline, `p.math-source` for display math), so it is typed
  into like any text. A click, ArrowLeft/Right into it, or a "$" typed so that
  it pairs around the caret opens it; the caret leaving it re-typesets it. In
  display math, Enter adds a line.
- **No jump to a made-up paragraph.** When the caret's source position was
  inside a block but on no text run (inside a formula, on a marker), `settle()`
  made an empty paragraph above and moved the caret there. Now a new empty
  paragraph is made only where no block holds the position on its text lines;
  otherwise the caret takes the nearest text place in that block.
- **Formula deletion.** Backspace after a formula removes its closing
  delimiter, Delete before one its opening delimiter (was: the whole formula).
- **Display math bounds.** `$$` blocks stop at a blank line (as in TeX), and the
  check used to interrupt a paragraph validates the closing delimiter first. A
  "$$" typed at a line's start no longer takes the notes below up to the next
  display formula.
- **Arrow keys.** Cross a heading's edges (its fold button and block count
  are no longer counted as text); reach a paragraph of only a formula or image;
  step out of bold, a code span or a link that ends (starts) a block.
- **Inline edges.** Emptying a code span or emphasis removes its markers;
  typing at an escape ("\*") lands on the side the caret is on.
- **Lists.** Enter on an empty item leaves a blank line (the next text was a
  lazy continuation of the item above); "- [ ] " with no text renders as a
  task item, and typing goes into it.
- **Focus kept.** An empty paragraph made by Enter stays in place over the
  pause render; partial renders (Enter, "$", backtick) update the focused
  block in place (`previewCache.place`).
- **Links.** In the selection toolbar, inside a link: change its address or
  remove the link, keeping its text.

## Automated checks

- All 126 unit tests pass.
- Browser cases on CI: 239 passed (default and reduced-motion projects), none
  flaky. Locally, the 165 cases of the related specs passed.
- New browser cases: formula at the caret shows its source and the caret stays
  in its paragraph; click, arrow keys and display formulas; "$$" at a line's
  start; heading edges and stepping out of bold; emptied code span and
  escapes; list exit, empty task item and the empty paragraph's focus over the
  pause render (no focus events); changing and removing a link.
