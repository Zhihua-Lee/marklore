# v0.5.0 Edit mode on the drawn note; proposals reviewed change by change; note properties; index-file order

## Changes

- **Edit mode (src/rich, ProseMirror).** Edit mode shows the note as the
  reading view draws it and takes typing in place; the source pane is off
  by default and stays in step both ways when shown. Typed Markdown becomes
  formatting once it reads as such (Settings → Edit → Literal typing keeps
  it escaped); formulas open as TeX where they stand; tables, lists, task
  lists, links, images, inline HTML (color, highlight), `<details>` folds,
  code blocks (highlighted, language field with a filtered list of known
  languages) and front matter are edited in place. A floating formatting
  toolbar, a selection toolbar, find and replace, comments and per-tab undo
  work in the editor. Saving keeps untouched blocks byte for byte and
  merges a changed block onto its source; a note that does not read back
  exactly falls back to the source pane with a notice. The previous direct
  editing in the preview, block editing with the pencil and their setting
  are removed.
- **AI proposals.** Fixed review colors (green added and underlined, red
  removed and struck through), three views (changes in place, side by
  side, source diff), accept or reject per edit (the remaining edits are
  found again by their exact old text), change marks on the reader's right
  edge. Word diffs never cut inside a word. `get_proposal` reports each
  edit's result.
- **Note properties.** Front matter reads as a folded line (date, weekday,
  time; notebook › section) and unfolds to a row per property; technical
  keys wait under "N more". One renderer serves Read and Edit mode; in
  Edit mode simple values change in place (numbers stay numbers), and
  nested values are changed in the source.
- **Index-file order.** A folder with `_目录.md` or `SUMMARY.md` lists its
  notes in the index's order with sub-pages; drag and Alt+Up/Down rewrite
  only the index's list (desktop/folder-index.mjs, files.mjs). The tree
  has one arrow column and a guide line per level.
- **Diagrams** are drawn by Ondine (WASM); mermaid.js is the fallback. The
  page CSP allows WASM compilation.
- **Reading:** optional bold/italic beside CJK text (Settings → Reading
  typography, off by default); inline code contrast.
- DOMPurify 3.4.17. Electron unchanged (44.9.3).
